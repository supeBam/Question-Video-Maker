# 短视频文案拆解与改写

本 Skill 由 Agent 负责内容分析和文案创作。项目脚本只提供基础的文本结构统计，不会调用生成模型，也不会自动产出多个改写版本。

## 工作流程

1. **取得原稿**：使用用户提供的文本/文件。若只有抖音系视频链接，需要抓取详情或转写时，先按 `douyin-competitor-video` Skill 获取材料。
2. **拆解可复用结构**：提炼主题、开场钩子、信息顺序、节奏、情绪变化和结尾方式。复用选题、知识点或结构时，逐句文案必须重写。
3. **核对新稿事实**：涉及历史、文学、人物或数据的具体说法，先查可靠来源；不确定的内容明确标出，不把推测写成事实。
4. **按用户目标改写**：围绕新主题或新角度写出完整口播稿。用户指定多个版本或相似度档位时，再按要求给出对应版本；默认给一个主稿和简短的结构说明。
5. **口语化校稿**：检查朗读是否顺畅、信息是否具体、句子是否适合视频节奏；删掉空泛铺垫和无依据的夸张表达。
6. **保存或衔接出片**：只有用户要求落盘时才保存文件；按用户指定路径和格式写入。用户要求生成题库或对话 JSON 时，使用对应数据结构和既有生产脚本，不虚构不存在的目录或 API。

## 项目辅助脚本

`scripts/rewriter/extract-script.py` 是可选的基础分析工具，支持 `--text`、`--video`、`--input` 和 `--output`。它输出句子数量、句长、简单关键词和基于词表的情绪标签；这些结果仅供参考，不能替代对内容结构、事实或受众的判断。

视频转写优先按 `douyin-competitor-video` Skill 的 FunASR 流程处理。辅助脚本不负责自动改写、相似度测量、AI 文风检测、项目档案管理或 TTS 合成。
