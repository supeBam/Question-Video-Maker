# 视频号钩子起手设计

给知识问答类短视频设计「前 3 秒」的钩子：主标题大字、挑战词、封面话术、口播第一句。

核心信念：**前 3 秒是进入推荐的敲门砖，而收藏/评论/关注是 2024 年后抖音官方加权的深度行为。** 钩子要同时服务两个目标：让观众 3 秒内停下（留存），以及让他产生"要收藏/要评论"的动作（深度互动）。只做前者不做后者，是 2024 年以前的打法。

> 证据等级说明（详见本项目 `docs/方法论/20260829-钩子方法论考究.md`）：
> - **A 官方**：抖音 2024 年算法提高收藏/评论/关注深度行为权重（[亿邦动力报道](https://www.ebrun.com/20241111/564315.shtml)）
> - **B 第三方共识**：蝉妈妈「黄金 3 秒」量化指标；3 秒留存 ≥60%、完播 ≥35% 的经验门槛
> - **C 案例观察**：本项目 4 条对标视频拆解（点赞 1.4万/5.5万/10万×2，n=4）
> - 公式库中每条公式都标注证据等级；未标注来源的表述一律视为行业共识（D），不作"有数据支撑"的承诺。

## 一、好钩子的五原则（设计时逐条自检）

| 原则 | 为什么 | 自检问题 | 证据 |
|---|---|---|---|
| 1. 数字具体化 | 数字制造标准与胜负感，「答对 8 个」比「答对很多」有压力 | 有没有数字或明确标准？ | D |
| 2. 挑战/悬念 | 挑衅观众（你行吗？）或制造缺口（到底指什么？），大脑才会停 | 观众有没有"被叫板"或"想知道"？ | C（n=4 案例观察） |
| 3. 身份代入 | 喊出特定的人（家长/学生/老人），"跟我有关"才停留 | 这 2 秒在跟谁说话？ | D |
| 4. 结果承诺 | 告诉观众"做对了能得到什么"（学霸/金榜题名/孩子语文好） | 答对的奖励是什么？ | C |
| 5. 收藏指令 | 收藏是官方 2024 年点名的深度行为，直接引导收藏比任何话术都值 | 观众有没有被"下指令"收藏？ | **A** |
| 6. 一句话能说清 | 大字标题 ≤12 字，超出即信息过载 | 念一遍要几秒？ | B（黄金 3 秒要求 3 秒内读完） |

**原理**：短视频没有"慢慢进入"，钩子不是自我介绍，是把"最狠的那句话"先甩出来。对标实测：10 万赞视频的标题全是「学霸都考哭了」这种 6 字挑战句，而不是「古人说话有多文雅」这种抽象感叹（C 级证据）。

## 二、钩子公式库（按场景选用，均标注证据等级）

### 1. 挑战式（通用首选）【证据 C：n=4 案例中两条 10 万赞均含挑战结构】
用数字 + 挑衅制造压力。
- 「10 题答对 8 个算你牛」
- 「学霸都考哭了」（隐含：你会不会哭？）
- 「能全对的，没几个人」

### 2. 悬念式（用第一题做钩子）【证据 C：10 万赞④以「王婆卖瓜卖的是什么瓜」开场】
直接抛出最有悬念的一题当开场。
- 「「社稷」指什么？」（后面接：10 题答对 8 个算你牛）
- 「月亮原来不叫月亮，叫什么？」

### 3. 身份式（家长/学生/老年受众优先）【证据 D：行业共识，未量化】
喊出观众身份 + 利益绑定。
- 「能全对的，孩子语文不差」
- 「答错 3 个以上，别说自己是语文老师」

### 4. 指令式（收藏驱动）【证据 A：收藏是抖音 2024 官方加权的深度行为】
直接下收藏指令。对标 4 条标题全部含「收藏」字样。
- 「帮孩子收藏，期末考到就是赚到」
- 指令式常与其他公式叠加，不单独用

### 5. 结果承诺式（画面角标/片尾）【证据 C】
给"全对"一个称号，制造自我肯定。
- 「全对 = 学霸」「全对，金榜题名」

**组合规律**：一条视频的钩子体系 = 主标题（挑战式/身份式）+ 挑战词胶囊（数字具体化）+ 角标（结果承诺）+ 收藏指令（A 级证据，必带）。封面、开头、发布标题三处用同一套话术。

**使用纪律**：引用证据时只说自己配得上的话——对用户说「10 万赞案例里出现过挑战式钩子」而不是「挑战式钩子能带来 10 万赞」；说「收藏是官方加权的行为」而不说「加收藏指令必爆」。

**后缀轮换纪律（防同质化，2026-09-07 起）**：发布标题 = 第一题悬念句（期期不同）+ 轮换后缀。挑战词后缀**不得连续两期重复**，从 5 个公式轮着取（挑战式 / 结果承诺·段位 / 身份式 / 收藏指令 / 悬念式）；段位后缀对准 `outro.scoreHints` 的段位名（文曲星下凡 / 出口成章 / 腹有诗书）。抖音话题 ≤5 个（最好 1~3 个垂直词 + 2 个泛流量词）。标题流量公式与话题规则详见 `docs/标题流量方法论.md`。

## 三、坏钩子清单（看到这些就要改）

| 坏钩子 | 为什么坏 | 改法 |
|---|---|---|
| 抽象感叹：「古人说话有多文雅」 | 陈述不是挑战；抽象不指向内容；对谁都不说话 | 改成「10 个古词，全对算你厉害」 |
| 无数字：「文学常识大挑战」 | 没有标准就没有压力 | 加数字：「10 题 · 答对 8 个」 |
| 身份模糊：「来测测你的水平」 | 没喊出具体的人 | 点名：「家长来测」「孩子来答」 |
| 信息过载：「中国文学常识大全 100 题 涵盖所有朝代…」 | 前 3 秒读不完（黄金 3 秒，B 级证据） | 只留最狠的一句 |
| 无悬念的陈述：「今天讲 5 个成语」 | 观众没有"想知道"的理由 | 「第 3 个成语 90% 的人用错了」 |
| 只钩留存不钩收藏 | 2024 年算法深度行为（收藏）权重已上调（A 级证据） | 主钩子里或结尾加收藏指令 |

## 四、输出格式（固定模板）

输入：选题/题库内容、题量、目标受众、平台（视频号/抖音）。
输出（不要少于 3 个候选，就 3 个，让用户选得动）：

```
【主钩子（大字标题，≤12 字）】
  1. 「……」 — 公式 N + 为什么
  2. 「……」 — 公式 N + 为什么
  3. 「……」 — 公式 N + 为什么

【挑战词（钩子开场胶囊，一个数字句）】
  「10 题 · 答对 8 个算你牛」

【封面大字（4-10 字）】
  「……」

【口播第一句（前 3 秒念出来的话，≤15 字）】
  「……」

【落到项目模板（如用 BurstQuiz 快闪模板）】
  intro.title: 「…」
  publish.challenge: 「…」
  publish.title: 「…」
  douyin.title: 「…」
```

每个候选必须标注**命中哪个公式**（见第二节），这是防止写出"无来源的漂亮话"的关键——漂亮的钩子要能说清它为什么勾人。

## 五、完整示例

**输入**：词语代称题库（社稷/汗青/桑梓/杏林/须眉…共 10 题），受众=家长+学生，平台=视频号+抖音。

**输出**：

【主钩子（大字标题）】
  1. 「10 个古词，全对算你厉害」 — 公式 1 挑战式 + 数字「10 个」有标准，「算你厉害」有胜负
  2. 「「社稷」指什么？」 — 公式 2 悬念式 + 用第一题当钩子，对标 10 万赞「王婆卖瓜」路线
  3. 「能全对的，孩子语文不差」 — 公式 3 身份式 + 喊家长，利益绑到孩子成绩

【挑战词】「10 题 · 答对 8 个算你牛」

【封面大字】「10 个古词\n全对算你厉害」

【口播第一句】「社稷的稷，是谷神的稷吗？10 题见分晓」

【落到项目模板】
  intro.title: 「10 个古词\n全对算你厉害」
  publish.challenge: 「10 题 · 答对 8 个算你牛」
  publish.title: 「古人的词语代称，全对算你厉害」
  douyin.title: 「「社稷」指什么？10 题答对 8 个算你牛」

## 六、数据闭环验证（比任何二手方法论都重要）

外部方法论最高只能到 B 级（第三方共识）。**唯一能证明"这些钩子对我们这个号有效"的是我们自己的发布数据**。每次用户给出发布数据时：

1. 记录：3 秒留存率、完播率、收藏率、评论率、转发数（创作者后台可见）。
2. 对照：与历史视频对比（同主题同模板最好，不同则说明差异来源）。
3. 参考线（B 级共识，用作方向判断而非死线）：3 秒留存 ≥60%、完播 ≥35%、收藏率环比变化。
4. 回写：把验证结果写进本项目 `reports/` 与本节——验证成立的公式升级标注为「本项目已验证」，被推翻的公式降级或删除。

判定口径要诚实：单条视频的数据受选题、时段、推荐运气影响，**至少 3 条同公式视频**的留存/收藏表现一致，才算"本项目验证"。
