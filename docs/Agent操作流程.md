# Agent 操作流程

目标是让 Agent 从“用户想做什么”走到可核验的交付物。运行命令前先读根目录 `AGENTS.md`；首次安装、依赖或渲染排错时读 [使用流程](使用流程.md)。

## 1. 判定任务与依赖

从用户需求确定：内容类型、题量 / 时长、是否配音、所需交付物和是否只写文案。未指定时，答题类先用 `BurstQuiz` + 手工配音模式验证流程。复现已有示例无需作为新选题登记；创作正式新内容执行 `AGENTS.md` 的查重与记录规则。

| 任务分支 | 必读入口 | 完成这一阶段的条件 |
|---|---|---|
| 答题或填空 | `src/types.ts`、`docs/方法论/爆款快闪模板.md` | 确定 schema、题型与事实依据 |
| 画卷展示 | `src/ScrollShow.tsx`、现有 `scroll-show-*.json` | 确定 items 数据和逐条音频来源 |
| 口播文案改写 | `.agents/skills/script-rewriter/SKILL.md` | 有校对后的原稿及新稿目标 |
| 对标分析 / 转写 | `.agents/skills/douyin-competitor-video/SKILL.md` | 已确认可用的浏览器工具 / ASR；插件不随仓库安装 |
| Hypit 视频 | `.agents/skills/hypit/SKILL.md` | 已有 Hypit 运行环境和实际工程；本仓库不附带 `work/` 工程 |
| 对话 / 故事 | 对应 `scripts/dialogue/` 或 `scripts/story/` 的目标脚本 | 脚本参数、数据与本地素材依赖均已核对 |

外部工具不可用时，报告具体缺项，并继续完成独立的文案、数据或本地演示部分。不要假定其他人的插件、登录态或 `work/` 目录存在。

## 2. 检查环境与输入

```bash
node --version
npm ci
npm test
npx tsc --noEmit
```

首次克隆使用 `npm ci`；依赖已安装且锁文件未变时可复用。真实入口以 `package.json`、`src/Root.tsx` 和目标脚本参数为准。

答题类先复制 `examples/questions-261105-1.json` 的结构。逐题核对：

- `id` 唯一；题干与答案完整；选择题索引在选项范围内，填空题含 `answer`。
- 事实、引用和多音字有依据；参考视频逐句文案经过重写。
- `meta.series`、`episodeLabel`、输出路径与本期一致。
- 背景、字体、音效、BGM 均可用且授权范围已明确；静音基线同时关闭 BGM、音效与配音。
- 新题库文件与题库记录同步完成。

## 3. 先预览，再渲染

```bash
npm run dev:data -- --data=examples/questions-261105-1.json
```

选择与数据匹配的 composition，确认文字无裁切、答案正确、节奏可读，然后停止预览服务。第一轮入门渲染：

```bash
npm run demo:render
```

正式数据运行：

```bash
npm run render:manual -- out/系列-第01期.mp4   --data=src/data/questions-YYMMDD-序号.json
```

以上正式数据路径是模板，执行前替换为实际存在的文件。同一工作区顺序渲染，避免共用 props 文件造成串期。自动 TTS 的依赖与命令见 [使用流程第 4 节](使用流程.md#4-可选自动-tts)。仅在用户授权外部生成后启用付费调用，保存状态并核对缓存后重试。

## 4. 验收并交付

逐一验证用户要求的产物，缺一个就报告一个，不把字幕单独生成或退出码 0 当作完整成片：

1. MP4：可播放，竖屏比例正确；抽看开头、每种题型揭晓和片尾。
2. PNG：能打开，标题完整、字号可读、没有明显裁切。
3. 手工配音模式：SRT 的文字和时间段与视频一致，TXT 文案对应本期。
4. 自动配音模式：试听题干、答案、片头片尾，检查多音字、截断和口播重叠；该模式默认不产 SRT。
5. 需要发布清单时运行 `publish:prepare` 并处理 blocking 项。只在明确授权范围内操作发布平台。

交付时给出：数据文件路径、实际命令、已生成文件路径、检查结果、仍缺的依赖 / 产物。没有试听或没有播放时如实标明。密钥、登录态和清单中的个人路径保持本地；提交前查看 `git diff --cached`。

## 可复制的任务示例

### A. 首次验收，无模型 API

> 阅读 AGENTS.md。使用 examples/questions-261105-1.json，运行测试和类型检查，然后通过 demo:render 生成 MP4、PNG、SRT 和 TXT。保持所有外部生成关闭，抽查答案与画面，列出实际产物路径。

### B. 正式新题库

> 制作一期三道中文文学选择题。先查题库记录，选择有增量的角度，核实事实并保存来源；按当天日期创建题库、同步登记。先预览并用手工配音模式出片，检查题目索引、字幕与封面，不发布。

### C. 用户已授权的自动配音

> 为我已确认的题库启用 MiniMax 自动配音。我授权本期 TTS 调用，密钥在本机 .minimax.key，不读取或回显密钥内容。先检查虚拟环境、requests 和 ffprobe；使用独立期号与 video-label，完成后试听题干和答案，检查口播重叠，并给出视频、封面、文案与实测时长文件路径。

### D. 文案拆解，不生成媒体

> 阅读 script-rewriter Skill。分析我提供的文本的开头、信息顺序和结尾，围绕同一主题写一个原创口播稿，标出需核查的事实。此任务只交付文案，不下载视频、不生成音视频。

### E. 修改程序

> 阅读 AGENTS.md，先复现我指出的问题，检查相关脚本和时间轴。修改后运行 npm test 与类型检查；涉及画面时使用无 API 示例验证对应帧，再说明行为变化和检查结果。
