# 答题音效设计

## 目标

为每道题增加两个固定启用的音效，不增加每期视频的音效配置：

- 画面倒计时进入最后 3 秒时，播放 `assets/audio/开始三秒倒计时.mp3`。
- 答案开始揭晓时，播放 `assets/audio/出正确答案的音频.mp3`。

背景音乐保持可选，并继续通过 `src/data/questions.json` 中现有的 `bgm` 对象为每期视频单独选择。

## 设计

新增一个职责单一的题目音效组件，在 `QuestionScene` 内渲染。组件使用相对于当前题目的局部帧，因此单题覆盖时间配置后，音效仍会自动对齐。

倒计时音效的开始帧为：

```text
max(countdownStart, revealStart - 3 * fps)
```

音效序列在 `revealStart` 结束，避免源文件尾部静音延伸到答案揭晓阶段。如果某道题的倒计时不足 3 秒，则从该题倒计时开始时播放。

正确答案音效在 `revealStart` 精确触发。两个文件都是模板固定资源，始终启用。

## 背景音乐

无需修改现有背景音乐代码。以后可以把音乐文件放在 `public/assets/bg-audio/` 下，并在题库 JSON 中选择：

```json
"bgm": {
  "enabled": true,
  "file": "assets/bg-audio/music-01.mp3",
  "volume": 0.22
}
```

题目音效音量与背景音乐音量互不影响。

## 验证

- 时间计算测试验证倒计时音效在揭晓前 3 秒开始。
- 时间计算测试验证短倒计时会把音效开始点限制在倒计时开始帧。
- 时间计算测试验证正确答案音效在揭晓帧开始。
- 使用 Remotion 合成发现命令验证项目可以打包并加载合成。
- 渲染同时覆盖两个触发点的短片段，验证输出视频包含音轨。
