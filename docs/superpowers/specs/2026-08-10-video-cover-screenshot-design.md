# 视频同名封面截图设计

## 目标

以后每次通过项目的正式渲染命令生成视频时，同时输出一张与视频同路径、同名的 PNG 封面图，不使用 AI 生图服务。

## 输出约定

若视频输出为：

```text
out/中国朝代历史-第02期.mp4
```

则封面输出为：

```text
out/中国朝代历史-第02期.png
```

## 截图画面

- 封面直接使用 Remotion 对 `LiteratureQuiz` 合成的静帧截图。
- 固定截取视频第 3 秒，对应当前 30 FPS 配置下的第 90 帧。
- 此时片头的栏目名、主标题、副标题、玩法提示和期号均已完成入场。
- PNG 尺寸与视频一致，沿用合成配置的竖屏宽高。

## 命令设计

- 新增一个 Node.js 渲染脚本，负责依次调用 Remotion 视频渲染与静帧渲染。
- `npm run render` 改为调用该脚本，作为今后正式输出视频和封面的统一入口。
- 脚本接受可选的视频输出路径；未提供时使用现有默认路径 `out/literature-quiz.mp4`。
- 封面路径由视频路径自动替换扩展名得出，不要求用户重复填写。

## 错误处理

- 只接受 `.mp4` 输出路径，其他扩展名立即报错。
- 视频渲染失败时不继续生成封面。
- 封面渲染失败时整个命令返回失败，避免误认为交付物完整。
- 已存在的同名 MP4 和 PNG 由 Remotion 正常覆盖。

## 测试与验收

- 自动化测试验证 `.mp4` 到 `.png` 的同名路径转换。
- 自动化测试验证非 `.mp4` 路径被拒绝。
- 执行统一渲染命令后，MP4 与 PNG 均存在。
- PNG 为视频第 3 秒画面的竖屏截图。
- 项目现有测试继续通过。

## 范围外事项

- 不新增独立封面场景。
- 不调用 AI 图片生成服务。
- 不改变片头现有视觉设计。
