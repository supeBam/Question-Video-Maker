# 内容审核基准（视频号 · 抖音）

> 用途：内容审核官对题库文案与成片执行合规审核的基准，依据《微信视频号运营规范》与《抖音社区自律公约》整理，聚焦本项目（古诗词/文化冷知识答题短视频）的典型风险。
> 依据：微信视频号运营规范（weixin.qq.com 官方页）、视频号违规营销治理公告、抖音社区自律公约。平台规则会更新，遇到新规以最新官方文本为准。

---

## 一、审核结论分级

| 结论 | 含义 |
|------|------|
| ✅ 放行 | 无违规风险，可发布 |
| ⚠️ 修改后放行 | 有低风险表述或瑕疵，给出具体改法，改完即可发布 |
| ❌ 不通过 | 存在明确违规或高风险内容，需重写/撤题 |

---

## 二、高危红线（命中即 ❌）

1. **政治敏感**：题目不得影射、评论、调侃现实政治、领土、民族、宗教政策；历史题只谈古代史实，不做古今对照影射（如"古代科举 vs 现代高考"的引申对比要克制，不讽刺现行制度）。
2. **医疗/养生误导**：不出涉及诊断、治疗、用药、偏方、食疗治病、风水运势、命理吉凶的题目（视频号规范 5.13、5.15–5.20 明令限制）。
3. **不实信息**：题干与解析中的"冷知识"必须有可靠出处（古籍原文、权威词典、博物馆官方），不得把网络段子、无据野史写成断然事实（视频号 5.4"不实信息"）。
4. **诱导互动**：不得以奖励、诅咒、道德绑架诱导点赞/关注/评论/转发（如"不点赞不是中国人""关注抽奖""转发保平安"）。片尾常规 CTA「点赞 + 关注」属可接受范围，但不得升级为利益诱导。
5. **营销导流**：画面、文案、评论区文案不得出现微信/手机号/二维码/第三方平台链接，不得引导私域（视频号 2025 起严打私域引流）。
6. **低俗色情/惊悚**：不借"两性""房事""绿帽"等词做噱头化标题；涉及此类俗语若只讲词源且表述克制可保留，但标题、封面不得放大低俗联想。
7. **版权**：诗句仅用公版（作者已故逾 50 年）；不用现代人诗句、歌词、影视台词出题；BGM 必须来自可商用授权渠道（Pixabay/YouTube Audio Library 等），不得扒平台热歌；素材图自绘或用可商用素材。

## 三、两种题型的审核要点

### 3.1 选择题（type: "choice"）—— 中国文化冷知识 / 文学常识 / 朝代历史 / 词语代称 / 成语
- **题干**：表述是否准确、无歧义；「\n」断句是否通顺；是否有误导性前提（如把野史当史实设问）。
- **选项**：正确答案必须唯一且无争议；干扰项不得含错误常识硬伤（干扰项也代表账号内容质量）；选项间不得有贬损性词汇。
- **解析（explanation）**：是审核重点——必须给出权威出处；野史/传说必须标"据传"；不得给历史人物下定罪式结论。
- **punchline**：短句是否夸大、是否与解析一致。
- 本类高频风险：历史人物私德题（见 4.1）、俗语词源题（见 4.2）。

### 3.2 万物雅称填空（type: "fill"）
- **stem**：设问是否严谨——"古人给 X 的雅称"必须是**公认、可查证**的雅称，不能用生造词或仅见于单条网络帖子的词。
- **answer**：雅称字形正确（纤凝/望舒/金乌等易错字）；与题干事物一一对应。
- **explanation**：引文（如《楚辞》"前望舒使先驱兮"）必须真实存在、原文准确；列举的其他别称不得与题库其他题目重复（对照 `题库记录.md`）。
- **tag**：分类准确。
- 本类高频风险：雅称出处生僻时易"以讹传讹"——每个雅称必须有古籍或权威词典出处，无出处的撤题。

## 四、本项目高频风险点（⚠️ 重点排查）

### 4.1 历史人物私德类题目（如第 1、7 期）
- 涉及李白求官、白居易蓄妓、李绅奢靡、刘希夷被害等野史/传说时：
  - 必须标注"据传/传说/野史"，不能以断然事实口吻传播；
  - 避免"人设崩塌""诗里一套背后一套"这类拉踩贬损式定调（视频号 5.3.3 禁止捏造事实丑化他人、拉踩引战，历史人物名誉同样可被投诉）；
  - 题目立意建议转向"今人对古人的误读"，而非"给古人定罪"。
- 规避建议：同类内容优先选有正史/出土文献支撑的知识点；无把握的传说改做"你听说过吗"式的开放式科普，不做"真相是……"式的定论。

### 4.2 俗语误传/词源类题目（第 2、9、11、12 期）
- 词源考证类内容整体安全，但注意：
  - "无奸不商""无毒不丈夫"等考释要与权威辞书一致，避免以讹传讹；
  - "戴绿帽""衣冠禽兽"等带色彩词汇：解说只用史料原文，标题不放大低俗联想。

### 4.3 标题与封面
- 视频号 5.2.1 禁止"使用夸张标题，内容与标题严重不符"。
- **新发布标题零数字铁律（2026-08-28 用户确认）**：所有新标题禁用一切**无来源数字**（99%、90%、1% 等无统计依据的比例与绝对数）；可用**可验证数字**（有古籍/官方出处，如「全中国只有一处」——行什仅存于故宫太和殿）；无出处数字一律改定性表述「绝大多数人」，并沿用已验证钩子句式：颠覆认知（「从小就叫错了」「你天天说却不知道来历」）、挑战提问（「你能答对几题」「你都用对了吗」）、美感命名（「美到可以当名字」）、悬念断句（「酒不叫酒，茶也不叫茶」）。
- 存量标题（8 条已发布的 99%/90% 类）按用户 2026-08-28 决策暂不修改，替换文案备查于 `docs/审核报告/20260828-存量标题整改清单.md`；数据分析持续观察其是否触发限流，触发即按清单执行替换。
- 封面文字不得出现"震惊""速看"等低质标题党词汇堆砌。

### 4.4 片头/片尾 CTA 与 hook
- "点赞 + 关注""评论区告诉我"＝温和常规引导，✅；
- 不得出现：集赞解锁、关注抽奖、不关注会如何、转发才能看到答案等（视频号 4.4 诱导用户）。
- hook 中"每天一道冷知识"如与实际更新节奏不符，属轻微夸大，建议保持与真实更新频率一致（抖音对"虚假宣传/夸大"同样处罚）。

### 4.5 成片技术面（发布后风险）
- 无配音字幕可读：字号 ≥ 24px，题干 ≤ 40 字（README 已约束），保证手机端可读；
- AI 生成内容标注：若引入 AI 配音/人像，抖音要求显著标注"AI 生成"；纯图文排版动画暂不需；
- 时长与题目数量对应：60s 上下为视频号完播友好区间。

## 五、逐字段审核清单（每期题库 JSON 全字段）

| JSON 字段 | 检查内容 |
|---|---|
| `meta.series/episode/episodeLabel` | 期号与 `选题归档.md` 登记一致；栏目名不夸大（"中国文学常识"下不放非文学内容） |
| `meta.hostTag` | 账号标签不冒用他人账号名 |
| `timing.*` | 时长与题量匹配；快闪模式 check TTS 语速兜底与题间停顿（见 `docs/爆款快闪模板.md`） |
| `intro.kicker/title/subtitle` | 标题不夸张失实；subtitle 不与内容冲突（如"全中国只有一处"需属实） |

| `outro.headline/scoreHints` | 分档文案对应题数；无羞辱性分档（"答对 0 题"不能写贬损语） |
| `outro.cta/ctaSub` | 仅"点赞+关注"类温和引导；无利益诱导 |
| `outro.hook` | 评论区引导合规；"每天一道"与更新频率一致 |
| `voiceOver.enabled` | 若开启 AI 配音需核对抖音 AI 标注要求；配音文案与画面一致 |
| `bgm.file` | 版权来源可商用；文件路径真实存在 |
| `publish.title` | 与视频内容一致；无"震惊/99%/唯一"式无据夸张；字数适配双平台标题规范 |
| `publish.hashtags` | 无蹭敏感话题标签；无竞品导流标签；标签与内容相关 |

| `questions[].stem` | 设问准确、无歧义、无误导前提（见 3.1） |

| `questions[].answerIndex` | 与答案文字对应（0-based） |
| `questions[].explanation` | 权威出处 + 野史标注 + 无贬损定调（见 3.1） |
| `questions[].punchline` | 与解析一致、不夸大 |
| `questions[].tag`（fill） | 分类准确 |
| `questions[].answer`（fill） | 雅称字形正确、有出处（见 3.2） |
| `questions[].timingOverride` | 覆盖值不为 0/负数，不造成成片闪帧 |

## 六、审核流程

1. **文案阶段**（题库 JSON / 发布文案 / 封面标题）：对照第二、三、四节 + 第五节字段清单逐条排查 → 输出结论 + 修改意见（逐题列出问题与改法）。
2. **成片阶段**（最终成片 MP4 / 封面 / 字幕）：Remotion 渲染出片（无配音）→ 用户剪映加 TTS 配音 → 审核官对「剪映加 TTS 后的最终成片」按第八节清单复查。
3. 结论写入审核回复，⚠️ 项给出可直接替换的文案；船长/创作者改后复审仅需核对修改点。

- [ ] 期号/档位文案/作答提示与 JSON 实际配置一致

## 八、成片阶段（含 TTS）复查清单

> 适用：剪映加 TTS 配音后的最终成片。依据：视频号运营规范 6.3/6.4、5.11.4（配音与画面相关）、5.2.1（标题相符）、5.14（低质内容），及本节制作标准。

### 8.1 字幕与配音一致性

- [ ] 每句配音与画面文字要点一致：无读错字（雅称、人名、引文读音）、无与画面文字矛盾的内容
- [ ] 配音为口语精简版时，覆盖画面解析的核心信息（雅称、出处、含义），不遗漏关键点
- [ ] 配音与画面不相关（视频号 5.11.4「视频配音与画面不相关」）→ 直接 ❌
- [ ] 答案句（雅称）读音准确：杜康/不夜侯/手谈/丹青/灵泽/凉友

### 8.2 语速与节奏

- [ ] 语速约 4–5 字/秒；超过约 6 字/秒或明显拖沓 → ⚠️ 调语速
- [ ] 每题配音落在对应画面区间内：题干句在「呈现+思考」阶段读完；解析句 ≤ 揭晓段时长（6.5s），不压入下一题
- [ ] 片头（4s）/片尾（6s）配音不越界

### 8.3 音量与听感

- [ ] 人声响度高于 BGM：人声峰值约 -6dB、音乐峰值约 -18dB 以下，BGM 不压人声
- [ ] 倒计时音效不与题干朗读相互干扰（可在剪映把原片音轨音量调至 60–70%）
- [ ] 无爆音、无断句卡顿、标点停顿自然

### 8.4 画面与规格

- [ ] 字号 ≥24px，题干/选项手机端可读；剪映新增字幕/贴纸不遮挡核心内容
- [ ] 总时长与 JSON 推导一致（本期 102s），剪映导出后偏差 ≤1s
- [ ] 分辨率 1080×1920 竖屏、30fps、H.264 MP4
- [ ] 封面与 publish.title 一致、无标题党（视频号 5.2.1）；封面文字无错别字

### 8.5 平台合规复查（成片全片）

- [ ] 无联系方式/二维码/站外链接（导流红线）
- [ ] 片尾 CTA 无利益诱导（视频号 4.4.1/4.4.2）
- [ ] TTS 合成语音已显著标注（视频号 6.4：AI 生成/合成内容应显著标识；抖音同类要求）——建议发布文案或评论区注明「AI 配音」
- [ ] BGM 可商用授权凭证已留档（否则标存疑·需人工确认）
- [ ] 全片无低俗/惊悚/政治敏感画面

### 8.6 成片复核所需素材（请用户提供）

1. **剪映导出最终 MP4**（含 TTS 配音的版本）的本地路径；
2. **封面图路径**（最终使用的封面文件，若替换过 render 脚本产出的 cover.png 请给新文件）；
3. （可选）TTS 使用的音色与语速设置说明、剪映生成的字幕 SRT 文件；
4. （可选）若在剪映中调整过 BGM 音量，告知调整值；
5. 成片复核基于上述文件 + 题库 JSON（`src/data/questions-260827-3.json`）+ 本清单执行，输出 ✅ 放行 / ⚠️ 修改后放行 / ❌ 不通过。
