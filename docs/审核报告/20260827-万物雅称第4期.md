## 二、需修改项（可直接替换）

### 修改 1（必须）：f2 explanation 引文失真

**问题**：「西晋张华《博物志》：「饮真茶，令人少眠，故茶美称不夜侯，美其功也。」」并非《博物志》原文。据人民日报《人民周刊》2024-03-18《茶饮故事 趣谈文史》（官建文，人民日报出版社《茶饮趣谈》后记）考证：《博物志》卷四原文仅「饮羹茶，令人少眠」几字，**并无「不夜侯」之说**；「故茶美称不夜侯，美其功也」系网文拼接。此句若照播，属于「不实信息」风险（视频号 5.4），且有被观众纠错的风险。「不夜侯」的可靠出处为五代胡峤《饮茶》诗，见《清异录·茗荈》所载。

**现文案**：
```
西晋张华《博物志》：「饮真茶，令人少眠，故茶美称不夜侯，美其功也。」茶能提神，喝了整夜精神，古人索性封它个「不夜侯」的官当当。茶也叫「涤烦子」「瑞草魁」「苦口师」。
```
**替换为**：
```
「不夜侯」见于五代胡峤《饮茶》诗：「沾牙旧姓余甘氏，破睡当封不夜侯。」西晋张华《博物志》也说茶「令人少眠」——茶能提神，喝了整夜精神，古人索性封它个「不夜侯」的官当当。茶也叫「涤烦子」「瑞草魁」「苦口师」。
```
