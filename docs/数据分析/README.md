# docs/数据分析/ 目录约定

> 维护人：数据分析（数据分析师） ｜ 更新：2026-08-27（工作模式调整：Excel 导入制）
> 用途：存放 @每日文化小测 / 抖音号「片刻中华」自身运营数据的原始材料与分析报告，为选题与运营决策提供依据。

## 目录结构

```
docs/数据分析/
├── README.md          ← 本文件（目录约定）
├── 原始数据/           ← 【已冻结】历史 OpenCLI 落盘数据，仅作抖音侧历史参考基线，不再更新
├── 导入/               ← 用户每周导入的 Excel（唯一活跃数据来源）
│   ├── 抖音/           ← 抖音数据表格（抖音-20260821-20260828-全量指标.xlsx）
│   └── 视频号/         ← 视频号数据表格（视频号-20260821-20260828-动态数据明细.csv）
└── 分析报告/           ← 数据分析产出（按平台分篇，md 格式）
```

## 工作模式原则（2026-08-27 起生效）

1. **唯一数据来源 = 用户导入的 Excel**：数据分析只分析 `导入/` 下的用户表格，
   **不自行抓取数据**（停用浏览器与 OpenCLI；不再请求船长代跑 opencli douyin 命令）。
2. **原始数据/ 已冻结**：`原始数据/` 下 3 个文件（20260827-douyin-profile/videos-top20/stats-top5）
   降级为「历史参考基线」，仅作抖音侧 2026-08-27 快照的历史对比，不再更新。
3. **抖音 / 视频号严格分区**：
   - 导入按平台分子目录存放（`导入/抖音/`、`导入/视频号/`）；
   - 两平台数据**不得混算**：均值、基线、比率分别计算；
   - 需要跨平台对比时，单独成篇并在文中明确标注两平台口径差异。

## Excel 导入规范

- **存放位置**：`导入/抖音/` 或 `导入/视频号/`（按平台，勿放错目录）。
- **命名建议**：`YYYYMMDD-平台-内容.xlsx`，如 `20260827-抖音-作品数据.xlsx`、`20260827-视频号-作品数据.xlsx`。
  同一天多份用 `-2`、`-3` 后缀区分；「内容」可选：作品数据 / 账号概览 / 涨粉明细。
- **表头要求**：见下文「两平台最小字段要求」；表头行在第一行，日期统一 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:MM`。
- **转换流程**：Excel 为二进制，数据分析用 COM Excel（pwsh）转 CSV 后分析；转换失败时请船长协助。
- **口径提示**：请在表格中注明数据截止日期（如「数据截至 2026-08-27 12:00」），避免口径漂移。

### 两平台 Excel 最小字段要求

**抖音 · 单条作品明细（必填字段）**：

| 字段 | 说明 |
|---|---|
| 发布日期 | 作品发布时间 `YYYY-MM-DD HH:MM`（至少到日期） |
| 作品标题/期号 | 用于与题库期号对应（如「万物雅称第3期」） |
| 播放量 | 单条播放次数 |
| 点赞数 | 单条点赞 |
| 评论数 | 单条评论 |
| 收藏数 | 单条收藏 |
| 转发数 | 单条转发（分享） |

建议补充（有则更佳）：涨粉数、完播率、5 秒留存率、2 秒跳出率、平均播放时长、粉丝观看占比、主页访问量。

**抖音 · 账号概览表（建议随附）**：统计日期、粉丝数、关注数、获赞总量、作品总数。

**视频号 · 单条作品明细（必填字段）**：

| 字段 | 说明（视频号后台口径） |
|---|---|
| 发布日期 | 作品发布时间 |
| 作品标题/期号 | 与抖音同源内容对应 |
| 播放量 | 视频号后台「播放次数」 |
| 点赞数 | 点赞（红心） |
| 评论数 | 评论 |
| 转发数 | 转发 |
| 收藏数 | 收藏 |

建议补充：关注数（单条涨粉）、完播率、平均播放时长、分享人数。

**视频号 · 账号概览表（建议随附）**：统计日期、粉丝数、关注数（账号关注他人数）、作品总数。

## 分析报告命名规范

- 报告存放 `分析报告/`，文件名用**平台前缀**：`平台-YYYYMMDD-主题.md`；
  - 示例：`抖音-20260827-周复盘.md`、`视频号-20260827-周复盘.md`
- 双平台对比单独成篇，命名 `对比-YYYYMMDD-主题.md`，文中明确两平台口径差异；
- 每期报告包含：数据来源（Excel 文件名 + 截止日期）、关键数字、逐维度分析、
  结论与建议（标注「事实/推测」）、待补数据（仅限「请用户下次导表补充」，不再请求 OpenCLI 代跑）。

## 数据口径约定

- 平台字段按原始表字段名引用，不擅自改名；单位（万/亿）在报告中标明。
- 分析结论需区分「事实」（数据可见）与「推测」（需更多数据验证）。
- 引用 `原始数据/` 历史文件时，必须标注「历史快照 2026-08-27，仅作参考基线」。
- 外部行业基准引用必须带来源链接。
