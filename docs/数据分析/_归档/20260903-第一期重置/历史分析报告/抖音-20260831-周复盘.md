## 四、本周最大发现：出题节奏是均播时长的第一变量（事实+推测）

**同主题（词源冷知识）、相邻两期、节奏不同，均播时长差 3.6 倍：**

| 对比项 | 第15期 · 连中三元 | 第16期 · 七月流火 |
|---|---|---|
| 题库 timing | intro 4s + 首题呈现 6.5s + 倒计时 5s ≈ **15.5s 后才首次揭晓** | intro 3s + 首题呈现 2s（timingOverride）+ 倒计时 4s ≈ **9s 内首次揭晓** |
| 均播时长 | **7.01s（全场垫底）** | **25.30s（全场第一）** |
| 5s 完播率 | 20.77%（全场垫底） | 40.88% |
| 播放量 | 839 | 546（首日值） |
| 点赞率 | 1.43%（全场垫底） | 1.83% |

- 事实：15 期观众平均 7.01s 划走——**连第一题都等不到揭晓**（读题阶段约 10s 前就流失）；16 期同样内容平均看到 25.3s，能看完全部 4 题中的约 2 题揭晓。
- 事实：上期建议「第一题呈现 ≤2 秒、倒计时 ≤4 秒、12 秒内第一次揭晓、Intro ≤3 秒」在 16 期**全部执行**（题库 `questions-260828-1.json` timing 字段可证），均播时长立竿见影。
- 推测：15 期早档 06:00 发布叠加慢节奏（6.5s 呈现）导致「标题给了成语悬念、首屏却迟迟不出题」，2s 跳出 38.35% + 均播 7.01s 是双重证据。
- 事实佐证：14 期（避讳，intro 4s + 6.5s 呈现，同为慢节奏）完播率 0.94% 全场垫底；而节奏中等偏快的雅称系列（present 2~3.5s）完播率 2.80%~4.68% 全在中上游——**节奏排序与完播排序基本同向**。
