# 归档区说明

本目录统一收纳 `docs/数据分析/` 的历史文件。**所有归档均采用「移动」而非「删除」，可随时找回。**

## 两个子目录

### `20260903-旧导入/` — 旧导入数据文件

2026-09-03 目录重构时归档的旧导入数据（11 个 csv/xlsx）。

- 旧文件中的「重复」并非脏数据，而是同一视频在不同导出时点的**累计快照**（如抖音「万物雅称第二期」180→593），是增长衰减分析的唯一数据源。
- 覆盖发布日：抖音 2026-08-21 ~ 08-29、视频号 2026-08-06 ~ 08-29。
- 命名风格混杂（三套并存），快照导出日期多只能按窗口终点推断——正是重构动因。
- 恢复方法：复制回 `导入/<平台>/<颗粒度>/`（建议按新命名规范改名）。
