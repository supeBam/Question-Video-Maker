## 一、为什么需要重写指标：三条硬规矩

现有框架（2026-08-27 版）的指标定义本身没错，缺的是**比较规则**。补上三条：

1. **可比性优先于全面性**：一个指标如果不能在同一口径下跨期比较，就不进周复盘主表，只作参考。
2. **中位数优先于均值**：单条层面一律用中位数。爆款（如单条 1,680）会把均值拉高 20% 以上，让"平均表现改善"变成假象。
3. **每个指标都要能落到动作上**：完播率低 → 改节奏；转发率低 → 改片尾社交货币；关注率低 → 改引导。找不到对应动作的指标不纳入。

## 二、成熟度标准化（本体系的核心口径）

### 2.1 定义

**成熟度 M = 快照日期 − 发布日期（天）**。所有单条作品的指标，必须标明其成熟度。

| 成熟度桶 | 取值 | 用途 |
|---|---|---|
| D1 | M = 1 | 起量速度判断，最快反馈 |
| D3 | M = 3 | 中期判断，推荐池是否放大 |
| D7 | M ≥ 7 | **标准比较口径**，所有跨期对比的默认基准 |
| D0（发布当日） | M = 0 | 不作分析用，仅登记 |

### 2.2 铁律

- **跨成熟度不得直接比较数值**。D1 的 1,680 与 D7 的 1,477 不可同榜排名——这是 08-31 周复盘"16 期登顶"结论的失效原因。
- **跨成熟度只能比较"长尾系数"与"相对基线倍数"**（见 2.3）。
- 成熟度未知的作品，一律标注 `M=?` 并排除出所有排行与检验，只进"待补"清单。

### 2.3 两个衍生口径

**长尾系数 K = D7 播放 ÷ D1 播放**

| K 值 | 解读 | 动作含义 |
|---|---|---|
| K < 1.5 | 首日即见顶，无长尾 | 流量型内容，靠发布密度取胜 |
| 1.5 ≤ K < 3 | 正常衰减 | 默认区间 |
| K ≥ 3 | 强长尾，被推荐池持续放大 | 高价值内容形态，优先复刻 |

> ⛔ **2026-09-02 实测修订：本账号 K ≈ 1，该指标暂不适用。**
> 内容生命周期追踪显示：发布 3 天后日增长率 视频号 **0.94%**、抖音 **0.33%**（双平台各自独立复现，见 `03-分析方法库.md` 方法七）。即内容在 48–72 小时内见顶，**不存在长尾复利**。
> 处置：① K 从周复盘主表移出，**不再投入导表成本**去采集 D7 快照；② 上表"K≥3 优先复刻"的判据对本账号无效；③ 若未来出现新内容形态（如系列合集、长视频）且实测 D3 后仍有 >2%/天增长，则恢复该指标。

**相对基线倍数 R = 单条 D7 播放 ÷ 账号同期 D7 基线中位数**
- R ≥ 2.0 → 高表现作品，进入爆款归因流程（D4）；
- R ≤ 0.5 → 触发告警（见第五节）。

### 2.4 基线定义

**账号基线 = 滚动最近 8 周、同平台、同成熟度桶的中位数**。
- 作品数 < 20 条时（当前状态），用全部历史中位数，并标注"基线未稳定"；
- 基线每 4 周重算一次，重算时保留旧值以便对比；
- **两平台基线严格分开计算，禁止混算**（沿用现有分区纪律）。

## 三、指标树

### 3.1 北极星指标

> **周度同熟度播放量（D7 口径）** = 本周发布作品的 D7 快照播放之和

选它而不选"总播放"的理由：总播放含存量作品，受发布节奏与长尾双重污染，无法归因到本期动作；D7 同熟度口径下，它就是"本周这批内容到底值多少播放"的干净度量。

选它而不选"粉丝数"的理由：涨粉滞后于内容表现 1–2 周，做周度决策太慢。粉丝数作为结果指标跟踪。

### 3.2 结果指标（Outcome）

| 指标 | 口径 | 平台可得性 | 目标 |
|---|---|---|---|
| 周度同熟度播放量 | 本周新发作品 D7 播放之和 | 抖音 ✅ / 视频号 ⚠️（需快照） | 用户设定，v1 先跑 4 周基线 |
| 周净涨粉 | 周末粉丝 − 周初粉丝 | 抖音 ✅ / 视频号 ❌（缺账号概览，阻断项） | 同上 |
| 周互动总量 | 点赞+评论+转发+收藏 | 两平台 ✅ | 同上 |
| 爆款率 | 周内 R ≥ 2.0 的作品占比 | 依赖基线 | 观察项，暂不设目标 |

### 3.3 驱动指标（Driver，可操作）

| 指标 | 公式 | 对应动作 | 平台可得性 |
|---|---|---|---|
| 单条 D7 播放中位数 | median(D7 播放) | 排期与题材选择的直接输入 | 需快照 |
| 完播率 | 完整观看 ÷ 播放 | 低 → 调 `questions.json` timing、压缩题量 | ✅ 两平台 |
| 3 秒留存率 | 3 秒仍观看 ÷ 播放 | 低 → 改钩子/封面/标题 | 抖音 ✅ / 视频号 ❌（长期缺口） |
| 平均播放时长 | 平台原始值 | 与完播率交叉看"卡在哪一题" | ✅ 两平台 |
| 转发率 | 转发 ÷ 播放 | 低 → 补社交货币（片尾提问、可晒点） | ✅ 两平台 |
| 推荐率（视频号特有） | 推荐 ÷ 播放 | 低 → 社交裂变未启动 | 视频号 ✅ |
| 点赞率 | 点赞 ÷ 播放 | 内容吸引力 | ✅ 两平台 |
| 关注率 | 关注 ÷ 播放 | 低 → 加强关注引导与主页价值感 | ✅ 两平台 |
| 长尾系数 K | D7 ÷ D1 | 判断内容形态是否值得系列化 | 需快照 |

### 3.4 护栏指标（Guardrail，不可为涨播放牺牲）

| 护栏 | 阈值 | 越界处理 |
|---|---|---|
| **零数字铁律执行率**（新发标题无"99%/90%"等数字钩子） | **= 100%，硬护栏** | 任何播放收益都不换，立即整改 |
| 完播率滚动 4 期中位数 | 不低于基线 −10% | 暂停一切"提播放"实验，回到节奏调优 |
| 周发布条数 | ≥ 目标条数（当前 6–8 条/周/平台） | 不得为追求单条质量而断更 |
| 主题重复率 | 同主题 8 期内不重复（见 `AGENTS.md`） | 退回选题侧重出 |
| 存量标题 8 条异常 | 无异常下滑/限流/下架 | 触发则上报用户决策（D8 维度） |

## 四、结论分级与置信度（强制标注）

报告中的每一条结论，必须同时标注 `样本量 n` 与 `结论级别`。

### 4.1 结论级别

| 级别 | 判据 | 允许的用法 |
|---|---|---|
| **观察** | n < 5，或成熟度未统一 | 只能写进"待验证"，**不得作为决策唯一依据** |
| **假设** | 5 ≤ n < 8，且置信区间不含 0 | 可执行，但必须同步设计验证方案并登记决策台账 |
| **结论** | n ≥ 8，且置信区间不含 0，且混淆变量已控制 | 可写入 `审核基准.md` 等规范，作为默认做法 |

### 4.2 置信度

| 置信度 | 判据 |
|---|---|
| 高 | CI 不含 0 + 无已知混淆变量 + 双平台或跨期复现 |
| 中 | CI 不含 0，但存在已知混淆（如同时改了节奏与题材） |
| 低 | CI 含 0，或 n < 5，或成熟度未统一 |

> 实例改写：08-31 周复盘原句「**雅称类在视频号依旧垫底**」
> → 应写为：「雅称类完播率低于词源类（雅称 n=3，词源 n=3，两组全分离；置换检验双尾 **p=0.20**，未达显著；**观察级，置信度低**）。已进入分批观察队列，累计至 n≥8 再定论。」

## 五、告警阈值

| # | 告警 | 阈值 | 级别 |
|---|---|---|---|
| A1 | 单条 D7 播放低于同熟度基线 | R ≤ 0.5 | 警告 |
| A2 | 点赞率低于账号基线 | ≤ 基线 × 0.7 | 警告 |
| A3 | 完播率连续下滑 | 连续 3 期 | 警告 |
| A4 | 周发布条数不足 | < 目标 80% | 警告 |
| A5 | 存量标题 8 条异常 | 见 D8 四项检查 | **上报用户** |
| A6 | 护栏指标越界 | 见 3.4 | **上报用户** |
| A7 | 数据质量门禁不通过 | 见 `02-数据质量门禁.md` | **阻断，不出报告** |

告警只在监测层输出，**禁止在告警层做归因**——那是周复盘的活。

## 六、字段口径速查（两平台）

| 本项目口径名 | 抖音原始字段 | 视频号原始字段 | 备注 |
|---|---|---|---|
| 播放量 | 播放量 | 播放量（明细表，累计口径） | 视频号日表"播放"为当天新增，**与明细表不可相加** |
| 点赞 | 点赞数 | 喜欢 | — |
| 评论 | 评论数 | 评论量 | — |
| 转发 | 转发数 | 分享量 | 视频号另有"转发聊天和朋友圈"列，口径不同，不混用 |
| 收藏 | 收藏数 | — | 视频号明细表无收藏列 |
| 涨粉 | 涨粉数 | 关注量 | 视频号日表"关注"含存量贡献，与明细不等 |
| 推荐 | — | 推荐 | 视频号特有（朋友赞过链路） |
| 完播率 | 完播率 | 完播率 | 百分比原值，无需换算 |

**已知长期缺口（每期报告"待补数据"节重复列出，直到补齐）**：
1. 视频号无 3 秒留存 / 2 秒跳出率 → 首屏问题无法与抖音同口径对照；
2. 视频号无账号概览（粉丝总数、作品总数）→ 无法计算涨粉率与粉丝渗透率；
3. 两平台均无"答题揭晓前留存" → 无法判断观众是否等到答案，这是答题类内容的关键留存点；
4. D1/D3/D7 快照体系尚未建立 → 长尾系数与同熟度排行暂不可用。
