# 数据质量门禁

> 维护人：数据分析（数妙妙） ｜ 版本：v1.0 ｜ 创建：2026-09-02
> 执行时点：用户导入 Excel/CSV 之后、任何分析开始之前
> 自动化：`node scripts/analytics/deep-metrics.mjs --dq-only --wechat=<csv> [--douyin=<xlsx>|--douyin-csv=<csv>]`

---

## 一、门禁的目的

**宁可这周不分析报告，也不能用脏数据出一个错的结论。**

现状里最典型的问题不是数据错，而是"数据不全却照样出结论"——视频号缺账号概览已连续两周未补，报告照样写涨粉分析，只是换了个口径（用明细表"关注量"代替），读者很难察觉这两个数不是一回事。门禁就是把这类"凑合着用"变成显式的、有记录的决定。

门禁不通过时，分析师的第一动作是**把缺口报给用户补数**，而不是换口径绕过。

## 二、检查清单（12 项）

### 2.1 阻断级（B 类，任一不通过 → 不出报告）

| # | 检查项 | 判据 | 不通过的处理 |
|---|---|---|---|
| B1 | 数据新鲜度 | 快照日期距今 ≤ 10 天 | 请用户重新导出最新表 |
| B2 | 必需字段齐全 | 含：发布时间、播放量、点赞、评论、转发 | 请用户补字段后重导 |
| B3 | 主键唯一 | 「平台 + 标题 + 发布时间」无重复行 | 人工核对去重，不擅自删行 |
| B4 | 数值合法性 | 播放/点赞/评论/转发 ≥ 0，无空值、无 NaN、无文本混入 | 定位异常行，请用户核对 |
| B5 | 数值逻辑一致 | 点赞 ≤ 播放、评论 ≤ 播放、转发 ≤ 播放 | 定位异常行，多为平台口径差异，需人工确认 |
| B6 | 时间可解析 | 发布时间可解析为日期，且不晚于快照日 | 修正时间格式 |
| B7 | 台账可识别率 | 未识别条数 ÷ 总条数 ≤ 10% | 先处理 `out/ledger-unmatched-*.txt`，否则题材维度不可用 |

### 2.2 警告级（W 类，可出报告但必须标注缺口）

| # | 检查项 | 判据 | 缺失时的后果（必须写进报告） |
|---|---|---|---|
| W1 | 账号概览表 | **分两档**：① 有粉丝总数 → 通过；② 仅有单条涨粉数（无总数）→ 扣 12；③ 两者皆无 → 扣 25 | ②③ 均导致涨粉率、粉丝渗透率不可计算；② 仍可算"周净涨粉" |
| W2 | 首屏指标 | 含 3 秒留存 / 2 秒跳出 / 5 秒完播 **任一** | 首屏钩子效果无法量化。**按平台分别判定**（抖音提供 → 不扣分；视频号后台无此字段 → 扣分） |
| W3 | **D3+ 快照覆盖**（原 D7，2026-09-02 修订） | 本周新发作品中 M≥3 的比例 ≥ 80% | 成熟度不足，单条对比需标注"未标准化" |
| W4 | D1 快照覆盖 | ≥ 80% | 长尾系数 K 与起量速度分析不可用 |
| W5 | 存量作品单调性 | 存量作品播放量较上次快照不下降（容差 1%，平台缓存误差） | 若下降，标注平台可能回撤数据，历史对比需谨慎 |

> **W3 修订依据（2026-09-02）**：实测本账号内容在 **D3 后停止增长**（视频号日增长 0.94%、抖音 0.33%，双平台各自独立复现，见 `03-分析方法库.md` 方法七）。既然 D7 与 D3 数值近似等价，强求 D7 快照已无收益，故判据放宽至 M≥3、扣分由 20 降至 10。**这是用数据换来的豁免，不是放宽标准**——若后续出现 D3 后仍显著增长的内容形态，立即恢复 D7 判据。

### 2.3 评分与等级

- 任一 B 类不通过 → 直接判 **D 级（阻断）**；
- B 类全过后从 100 分起扣：
  - W1 −25（无任何涨粉字段）／**−12（有单条涨粉数，缺粉丝总数）**；
  - W2 −15（**按平台判定**，有首屏字段的平台不扣）；
  - W3 **−10**（2026-09-02 起，原 −20；已实测 D3 后停止增长）；
  - W4 −15；W5 −10（按缺失项累加）；
- 另设 **缺口账龄惩罚**：同一警告项连续未补 ≥ 3 周，额外 −10（防止"长期欠款"被常态化）。

> **评分解读**：双平台**分别评分**。实测（2026-08-29 快照）抖音因提供 2s 跳出率/5s 完播率而比视频号高 15 分——这 15 分买到了"首屏可诊断"的能力，是真实的能力差异，应反映在评分上。

| 等级 | 分数 | 允许的分析动作 |
|---|---|---|
| **A** | ≥ 90 | 全套：深度分析、统计检验、结论可升为"结论级" |
| **B** | 70–89 | 周复盘 + 描述性分析；结论最高只能到"假设级"，须标注缺口 |
| **C** | 50–69 | 仅监测层告警，不做题材归因 |
| **D** | < 50 或 B 类不通过 | **阻断**：只出缺口清单，请用户补数 |

## 四、三条纪律

1. **不换口径绕过**。字段缺失就是缺失，不许用另一个不等价的字段顶替后继续下结论；若必须替代，报告中每一处该指标旁都要标注替代口径。
2. **缺口要记账**。每个警告项记录"首次缺欠周次"与"连续缺欠周次"，连续 3 周由分析师正式向用户提出：要么补数，要么正式把该指标从指标字典中降级（并接受永久失去该视角）。
3. **脏数据不进基线**。门禁未通过的那批数据不得参与基线计算，避免污染滚动中位数。
