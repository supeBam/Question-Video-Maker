# 决策台账

> 维护人：数据分析（数妙妙） ｜ 创建：2026-09-02
> 用途：让每一条建议都不失联。**建议发出 → 决策 → 执行 → 到期回收 → 沉淀**，闭环。
> 回收纪律：每周一复盘时，筛出本周到期条目逐条判定；**证伪比验证更值得记录**。

## 一、字段说明

| 字段 | 说明 |
|---|---|
| ID | `D-YYYYMMDD-N`，提出日期 + 序号 |
| 决策问题 | 这条建议要回答什么问题 |
| 建议 | 具体动作，可执行 |
| 类型 | 执行 / 试做 / 暂缓 / 护栏 |
| 预期影响 | 量化区间 + 口径 |
| 采纳 | 采纳 / 部分采纳 / 未采纳 / 待定 |
| 验证指标 | 指标名 + 判定标准 + 样本要求 |
| 回收日期 | 具体到日 |
| 实际结果 | 回收时填 |
| 判定 | 验证 / 证伪 / 证据不足 |
| 沉淀 | 这条决策最终改变了什么做法 |
