# 抖音号「片刻中华」核心指标分析框架

> 维护人：数据分析（数据分析师） ｜ 创建：2026-08-27
> 用途：账号自身运营数据的分析口径与指标体系，每期复盘报告按本框架执行。
> 说明：深层指标（完播率等）需 `opencli douyin stats` 由船长代跑获取；本框架同时兼容用户导入的 Excel 数据。

---

## 一、指标层级总览（漏斗模型）

```
曝光/推荐流量（平台给量）
  ↓ 首屏吸引（封面/标题/hook）
播放量
  ↓ 3 秒留存 → 完播率（初始流量池的敲门砖）
互动（点赞/评论/收藏/转发）
  ↓ 互动浓度驱动二次推荐
涨粉（粉丝转化）
```

- **完播率是初始推荐池（0–500 播放）最重要的门槛指标**；进入更大流量池后互动浓度权重上升（来源：[蝉妈妈](https://www.chanmama.com/yunyingquan/question/4338.html)、[B站算法分析](https://www.bilibili.com/read/cv45263020/)）。
- 本项目视频为 60–85s 答题类，完播天然偏难；重点盯 **3 秒留存率**与**答题揭晓前留存**（观众是否等到答案）。

## 二、七大分析维度

### D1 账号基本盘（每周一更）
| 指标 | 含义 | 数据来源 |
|---|---|---|
| 粉丝数 | 当前总粉丝 | douyin profile / 导入 Excel |
| 获赞总量 | 历史累计点赞 | douyin profile |
| 作品数 | 已发布视频数 | douyin videos --limit 全量 |
| 周涨粉/周掉粉 | 粉丝净变化 | 相邻两次 profile 快照差值 |

### D2 单条作品核心指标（每期作品发布 3/7 天后各拉一次）
| 指标 | 口径 | 关注阈值（待实测校准） |
|---|---|---|
| 播放量 | 单条播放 | 记录发布后 3 天、7 天两个时点 |
| 点赞数 | 单条点赞 | 结合点赞率看 |
| 评论数 | 单条评论 | 答题类看「评论区作答」浓度 |
| 收藏数 | 单条收藏 | 收藏=想再看/学到了，文化类高质量信号 |
| 转发数 | 单条转发 | 转发=社交货币，决定出圈 |
| 完播率 | 完整观看/播放 | `douyin stats` 深层指标 |
| 3 秒留存率 | 首屏钩子效果 | `douyin stats`（若可得） |
| 平均播放时长 | 停留质量 | `douyin stats` |

### D3 互动质量（衍生比率，跨作品可比）
- 点赞率 = 点赞/播放；评论率 = 评论/播放；收藏率 = 收藏/播放；转发率 = 转发/播放。
- 对比基准：与选题数据文档中的竞品数据点（章放 639.8 万赞雅称、阿帅派克 615.4 万赞飞花令等）对齐口径后对比；同时与本账号自身历史均值对比（「优于自身均值」比「达到行业线」优先级更高）。

### D4 爆款归因（核心产出）
对「高表现作品」（超过自身均值 2 倍以上）做交叉归因：
| 归因维度 | 取值 |
|---|---|
| 题型 | 雅称填空 / 诗词填字纵横 / 冷知识选择 |
| 主题 | 万物雅称·酒茶棋画雨扇 / 诗人趣事 / 字网主题等 |
| 标题句式 | 颠覆认知式 / 数字钩子 / 雅称母题式 |
| 视频时长 | 60s / 72.5s / 85s |
| 发布信息 | 星期 / 时段 / 是否蹭热点 / 是否平台首发 |
- 输出：「什么题型×什么主题×什么标题」组合在本账号跑赢均值 → 反馈给选题侧与运营侧。

### D5 涨粉效率
- 单条涨粉数（发布后 7 天粉丝净增，`douyin stats` 若可得）；
- 涨粉/播放 转化率、涨粉/点赞 比；识别「涨粉型爆款」与「流量型爆款」的区别。

### D6 发布时间效果
- 按 星期 × 时段（早 7–9 / 午 12–14 / 晚 19–23）聚合播放与互动均值；
- 结合选题文档中「热点联动」（节气/诗词大会播出期）建议，验证热点期 vs 平时发布的效果差。

### D7 双平台对比（抖音 vs 视频号）
- 同一期内容双发时对比两平台点赞/评论/涨粉差异；
- 验证选题文档结论「视频号偏好人文共鸣、30–50 岁国风用户」，用本账号数据检验哪类内容在视频号跑得更好。

## 三、基线建立与告警

1. **冷启动基线**：账号历史不足 20 条作品时，不做均值对比，只做单条定性记录；满 20 条后计算各指标历史均值作为「自身基线」。
2. **告警阈值**（建议，待数据校准）：
   - 单条播放低于自身均值 50% → 提示选题/标题/封面异常；
   - 点赞率低于自身均值 30% → 提示内容吸引力下降；
   - 完播率连续 3 期下滑 → 提示节奏/时长/钩子问题（联系 README timing 配置调优）。
3. **口径纪律**：所有对比注明数据抓取日期；「事实」与「推测」分开写；引用的外部基准必须带来源链接。

## 四、报告输出规范

- 每期报告文件：`docs/数据分析/分析报告/YYYYMMDD-主题.md`；
- 结构：① 数据来源与原始文件 ② 本期关键数字 ③ 七大维度逐项分析 ④ 爆款归因结论 ⑤ 给选题/运营的可执行建议（可被选题侧直接采纳）；
- 报告末尾附「待补数据」（如需要船长代跑的 stats 命令清单）。

## 五、与团队其他角色的数据接口

| 接口 | 方向 | 内容 |
|---|---|---|
| 内容选题 ← 数据分析 | 提供 | 本账号题型/主题表现排行 → 选题优先级校准 |
| 内容审核 ← 数据分析 | 提供 | 标题/封面 A-B 效果数据（若可得），提示「标题与内容相符」的可验证数据点 |
| 运营/船长 ← 数据分析 | 提供 | 发布时段建议、双平台差异化发布建议 |
| 数据分析 ← 船长 | 接收 | OpenCLI douyin 代跑结果（原始数据/）、用户导入 Excel（导入/） |
