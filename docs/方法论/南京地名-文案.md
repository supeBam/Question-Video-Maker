今天想跟您唠一个事。
南京，六朝古都，咱们打小就熟。
可要问南京为啥又叫金陵，
金陵这俩字啥意思，
十个老伙计，九个得支支吾吾。
多数人张口就来：
金陵嘛，产金子，金山多。
这话呀，不对。
史书里头，白纸黑字记着：
战国那会儿，楚威王灭了越国，
在石头山这地方筑了一座城。
筑城的时候，他干了一件怪事——
在城底下，埋了金子。
不是埋来花的，
是埋来「镇王气」的。
有一种说法：这地方有王者之气，
楚威王怕它日后冲出天子，
就拿金子给它压一压。
打这起，这座城就叫金陵邑。
您听明白了吧，
金陵的金子，不是用的，
是镇风水的。
讲到这，先麻烦诸位老朋友抬抬手，
把屏幕底下那颗小红心按一下，
就当给咱们这座老城留个心意，
也让更多爱听老故事的朋友，
把这金子底下的讲究瞧个明白。
闲话搁一边，接着往下说。
可故事还没完。
一百多年后，秦始皇东巡，
听人说金陵有王气，
他心里不痛快——
我刚统一天下，
你这座城还敢憋着王气？
有一种说法：他干脆叫人凿开山体，
挖出一条河，把王气泄掉，
还把金陵改了个名，
叫秣陵。
秣是啥？喂牲口的草料。
好端端一座金陵城，
让他贬成了一片草场。
一个埋金镇王气，
一个凿山泄王气，
两位皇帝，跟这座城的王气，
前后较了一百多年的劲。
您再想想这座城的分量。
钟山龙蟠，石头虎踞，
长江天堑，三面环水，
自古就是帝王建都的风水宝地。
东吴在这儿立了国，
东晋在这儿偏安半壁江山，
宋齐梁陈，一代接一代，
六朝古都，十朝都会。
到了明朝洪武元年，
朱元璋在这儿登基，
把应天府定名南京。
南京这个名字，
一叫又是六百多年。
您再往深里琢磨：
从金陵邑算起，两千三百多年，
名字改了七八次，
金陵、秣陵、建业、建康、
江宁、应天、南京，
一座城，把大半部中国史
都装进名字里了。
可如今游客到了南京，
张嘴就是盐水鸭、夫子庙、
梧桐大道、南京眼，
你要问他金陵的金子埋在哪儿，
南京这个名字打哪来，
十个里头九个答不上来。
这座城守了两千多年，
守的是六朝烟水的风流，
守的是龙蟠虎踞的气象。
这份家底，
不能在咱们手里断了线。
劳您在评论区写下四个字：
金陵永安。
写给这座埋过金子的老城，
也写给自己。
您要是还有自己家乡的老地名，
想弄明白来龙去脉，
也请在评论区报个名，
下回，咱就唠您点的那座城。
末了多说一句，
有些老底子里的讲究，
晚知道一天，
根就薄上那么一层。
一座城，钟山脚下，
两千三百年文脉不断，
硬是把这块石头，
养成了王气不散的一份家底。
劳您点个关注，咱们不走散。
下回接着给您唠，
您点的那座城。

## 事实核查（训诂求真）

1. **楚威王灭越后（约前333年）于石头山筑金陵邑，传说埋金以镇王气**——通行说法（《建康实录》等），埋金说为流传最广版本；文案标「有一种说法」留余地 ✓
2. **秦始皇东巡（前210年），闻金陵有王气，凿方山、断长垄为渎（秦淮河），改金陵为秣陵**——通行说法 ✓
3. **「钟山龙蟠，石头虎踞」**：诸葛亮语（《吴录》），形容南京地势 ✓
4. **六朝古都**：东吴、东晋、宋、齐、梁、陈 ✓；**十朝都会**为通行扩展说法 ✓
5. **明洪武元年（1368）朱元璋于应天府称帝，以应天为南京** ✓
6. **金陵邑（前333年）距今约 2300 余年** ✓
