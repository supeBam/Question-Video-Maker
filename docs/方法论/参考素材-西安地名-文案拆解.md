# 参考素材拆解：视频号「西安地名」长视频

> 素材：`public/assets/参考素材/9月17日.mp3`（362s）+ `.srt`（174 句）
> 拆解日期：2026-09-17｜用途：试验田「地名唠嗑」类型的文案与声音学习

## 一、数据特征

- 时长 362s（6 分钟），174 句，1429 字，**语速 3.95 字/秒**（慢，中老年友好）
- 短句为主，一句一个信息点；口语虚词密集（您/老伙计/估摸着/压根/搁一边/捅破窗户纸）

## 二、文案骨架（可复用模板）

```
1. 钩子（0~10s）   熟人开场「今天想跟您唠一个事」+ 常识缺口「西安为啥叫西安」
2. 立靶（10~20s）  先立错误答案「十个老伙计有八个说西部安宁」→ 反转「正确答案让您吃一惊」
3. 中段互动（~25%） 不等结尾就要赞：「抬抬手按小红心」+ 利他理由「让更多上了岁数的朋友瞧个清楚」
4. 主体（~70%）    地理形胜 → 历史脉络，层层递进；一句一画面
5. 升华（~85%）    情绪收口：「华夏最厚重的家底」
6. 收尾            关注 + 下期预告「下回接着给您唠……」（卖书橱窗部分我们不学——未开通带货）
```

## 三、语气 DNA（唠嗑体）

- 称呼：您 / 老伙计 / 诸位老朋友（对中老年受众的熟人感）
- 动词口语化：唠、瞧、捅破、搁一边、赏饭吃
- 互动话术绑利他：不是「给我点赞」而是「让更多朋友瞧个清楚」

## 四、声音处理决策（合规红线）

- ❌ **不克隆该创作者真声**（民法典 1023 声音权；平台打击 AI 克隆真人）
- ✅ 用 MiniMax 音色设计生成**全新合成音色**：`laoke-dashu-01`（低沉醇厚、慢速、唠嗑亲切感）
  - 试听：`out/试听-唠嗑大叔.mp3`
- 气质相似 ≠ 声音相同：学的是语速、节奏、语气，不复制任何真人的声纹
