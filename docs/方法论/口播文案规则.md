# 口播文案规则（送 TTS 台本专用）

> 2026-09-21 用户拍板。适用于所有地名唠嗑、国学对谈等口播台本中送入 MiniMax 配音的正文。
> 文档性内容（事实核查清单、标题候选、设计说明）不受此限。

## 一、特殊符号禁令（防 AI 配音停顿）

口播正文只允许出现：汉字、逗号、句号、问号。谨慎使用顿号。

禁止清单（非穷尽，原则是「一切非汉字、非上述标点的符号都不进正文」）：

| 禁用 | 替代写法 |
|------|----------|
| 破折号 —— 或 — | 拆成两句，用逗号或句号断 |
| 直角引号 「」『』 | 直接去掉，或用「这个字」「那句话」等口语指代 |
| 方括号 【】[]（） | 删除或改为口语过渡 |
| 书名号 《》 | 改口语说法：诗经里头唱、史书上写 |
| 省略号 …… | 改成句号，靠句式本身留白 |
| 冒号引出式 A：B | 改「A，B」或「A说，B」 |
| 感叹号 ！ | 少用；语气靠词语本身（啦、呀、呗）承载 |
| 波浪号 ~、英文引号 ' " 、英文括号、分号 ;、斜杠 /、星号 *、间隔号 · | 一律删除或改写 |
| 阿拉伯数字 | 见「零数字铁律」，如需量级用汉字口语（十个老伙计九个……） |

## 二、既有纪律继续生效

1. 零数字铁律：标题与正文禁无来源数字；固定俗语量级（十人九不知）可用汉字写出。
2. 片头口播 = 封面大字，不念挑战词胶囊。
3. 钩子挑衅句式、评论区仪式、点单收口按系列骨架走。
4. 文言文引用保留原文但去书名号，用口语引出（诗经开篇就唱，天命玄鸟降而生商）。

## 三、生僻字处理（2026-09-21 补，踩坑实录）

冷僻字/多音字**不要用生僻同音字兜底**（TTS 见到不认识的字照样瞎读：契→qì，偰→也被读错）。三级处理顺序：

1. **首选绕开**：人名地名口语化（商族的始祖，不提单字名），零风险；
2. **次选同音常用字**：确需点名时用无歧义常见同音字替代（阏伯→烟伯），转写验证；
3. **禁止**：偰、卨这类生僻替代字——比原字更不可控。

## 四、交付前自检

1. 字符扫描：正文除汉字和 ，。？、外不得有任何字符；
2. **读音终审必须人耳过一遍**——whisper 转写只能抓大错（契 qì 那次抓到了），对生僻字会「将错就错」地转写成人耳听到的错音同音字，不可作终审依据；
3. 改句重合成后注意 TTS 缓存指纹：缓存键=模型+音色+语速+文本，改文本才会重合成；怀疑缓存污染时直接删对应条目重跑。
