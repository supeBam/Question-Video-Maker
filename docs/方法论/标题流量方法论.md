# 标题流量方法论（后续出题规则）

> 用途：给「后续出题」定死标题与话题规则——标题怎么利用流量、话题怎么不超限、怎么避免相邻期次标题雷同。
> 触发：生成题库 JSON 的 `intro.title` / `publish.title` / `publish.douyin.title` / `publish.hashtags` 时，逐条对照本文自检。
> 只约束**新出题**，不改动已发布的历史题目。

---

## 一、标题为什么决定流量

- **封面 + 标题决定约 50% 的推荐流量**（行业共识，[知乎·抖音标题撰写技巧](https://zhuanlan.zhihu.com/p/149779630)）。
- 标题直接决定完播率、点赞率、评论率——标题是「内容的精华」，内容不行标题补，内容好标题差也难火（同上）。
- 前 3 秒是进推荐的敲门砖；收藏/评论是抖音 2024 年官方加权的深度行为（本项目 `reports/20260829-钩子方法论考究.md`）。

一句话：**标题不是对视频的概括，是「让观众点进来 + 看完 + 动手」的钩子。**

---

## 二、好标题的三要素

| 要素 | 含义 | 本项目落地 |
|---|---|---|
| 有卖点 | 给观众「想得到的东西」：好奇、谈资、优越感、孩子成绩 | 颠覆认知、答对算你牛、文曲星下凡 |
| 有内容 | 文字有力、不歪曲、预告真实内容 | 第一题悬念句，不标题党 |
| 有趣味 | 有独特角度或态度 | 「从小就叫错了」「你天天说却不知道来历」 |

辅助特点：画面感（多用动词、断句）、找共鸣点/痛点、多用「我/你」、角度新颖观点鲜明。

---

## 三、写标题的 3 步流程（可执行）

1. **思考内容**（四个问题自问）：给谁看？表达什么？哪点最吸引眼球？凭什么让人留下看完？
2. **起草 5~10 个**：提取关键词（栏目、第一题、受众、结果），串成多个候选，读一遍看通不通。
3. **修改定稿**：挑最优，加共鸣点或悬念，**不要全盘托出**（留一点「是什么/为什么」给视频揭晓）。

> 纪律：不要凑合、不要不写、不要照抄上一期后缀（见第七节）。

## 四、标题公式库（落到本项目）

外部方法论归纳（[亿邦动力·10 个套路](https://www.ebrun.com/20220511/483908.shtml)、[知乎·5 类型 3 套路](https://zhuanlan.zhihu.com/p/149779630)），与本项目 `wechat-video-hooks` 技能合并成下表：

| 公式 | 含义 | 示例（适配成语/文化冷知识） |
|---|---|---|
| 悬念式 | 话说一半，留缺口 | 「「社稷」指什么？」「酒不叫酒，茶也不叫茶」 |
| 挑战式 | 数字 + 挑衅 | 「10 题答对 8 个算你牛」 |
| 颠覆认知 | 挑战刻板印象 | 「你天天说的成语，意思全反了」「从小就叫错了」 |
| 数字具体化 | 数字制造标准与压力 | 「10 题 · 答对 8 个」 |
| 身份代入 | 喊出特定的人 | 「能全对的，孩子语文不差」 |
| 共鸣/痛点 | 感同身受 | 「这些词你天天说，来历没几个人知道」 |
| 收藏指令 | 引导深度行为（官方加权） | 「帮孩子收藏，期末用得上」 |
| 结果承诺 | 给「全对」一个称号 | 「全对就是文曲星下凡」「答对 8 个，出口成章」 |
| 故事感 | 一句话讲一个故事 | 「俞伯牙摔琴，是为谁？」 |

**抖音标题结构（本项目固定模板）**：`「第一题悬念句」 + 轮换后缀`。第一题悬念句期期不同（天然差异点），后缀按第七节轮换。

### 四·补：特征叠加规则与「态度型」钩子（2026-09-15 增补，数据来源：洁净窗口 27 条实测）

**背景**：非答题形式（反差陈述式）上线后，标题不再带「考考孩子/快收藏」指令，与旧规则冲突。经数据检验，规则修订如下。

**1. 视频号新增第 6 种合法偏好：态度型钩子**——不是工具指令（考孩子/收藏），而是「替用户表态/自我检验」：`敢不敢自测一下`、`你能答对几个`、`90% 的人都理解错了`。转发动机从「工具」变为「态度」，避开熟人社交场的自曝尴尬。

**2. 特征叠加是播放量的第一决定因子**（洁净窗口实测，中位播放）：

| 标题命中增益特征数 | 0–1 项 | 2 项 | 3 项 | 4 项 |
|---|---|---|---|---|
| 中位播放 | 482–596 | 695 | **1171** | **1154** |

增益特征清单：`数字`（2.11x）、`互动指令`（2.31x，非答题型内部 3.46x）、`反常识标记`（不是/其实/居然/用错，1.66x）、`第二人称`（你/您，1.61x）、`问号`（1.33x）。

**3. 硬规则**：
- 每期视频号标题**必须命中 3–4 项增益特征**（2 项以下不合格，5 项有过满反例）；
- **「古人/古代」是实测负面词（0.40x）**——标题避免以它开头，具体词（成语/老话/称呼）优于抽象朝代词；
- 互动指令不降格为工具：优先用「自测/答对/敢不敢」而非「考考孩子/快收藏」。

## 五、抖音 vs 视频号标题差异

| 平台 | 标题取法 | 偏好 |
|---|---|---|
| 抖音 | 短钩子（首行，≤ 约 20 字） | 悬念 + 数字 + 挑衅，前 3 秒读完 |
| 视频号 | 完整句（可稍长） | 人文共鸣 + 利益绑定（考考孩子/收藏） |

当前脚本：抖音取 `publish.douyin.title`（或 `intro.title` 首行），视频号取 `publish.title`（或 `intro.title` 整句）。写 JSON 时两处都要单独给，别共用。

## 六、话题规则（抖音 ≤5，最佳 1~3）

- **硬规则：抖音一条视频话题最多 5 个**（平台限制），超出会被视为堆砌、可能限流。
- **方法论共识：话题不是越多越好，选 1~3 个最贴合的即可**（[知乎](https://zhuanlan.zhihu.com/p/149779630) 明确「选择 1-3 个话题标签即可」）。
- **落地组合**（成语栏目示例）：

| 平台 | 话题 | 数量 |
|---|---|---|
| 视频号 | `#成语 #成语故事 #冷知识`（2~3 个垂直词） | 2~3 |
| 抖音 | 垂直词 + `#涨知识 #知识分享`（泛流量词） | ≤5 |

- 规则：`publish.hashtags` 只写 2~3 个**栏目垂直词**，不写泛流量词；抖音发布时可手动补 `#涨知识 #知识分享`，总数卡在 5 以内。
- 兜底：导出脚本 `scripts/quiz/render-with-cover.mjs` 会自动把抖音话题截断到 5 个，即使 JSON 写多了也不会超限。
- 禁用：蹭敏感话题、竞品导流标签、与内容无关的热点标签。

## 七、去同质化：后缀轮换

**根因**：历史 4 期抖音标题尾巴全是 `10 题答对 8 个算你牛`、视频号尾巴全是 `答对 8 个算你牛，快收藏考考孩子`——后缀期期一样，第一题悬念句的差异被淹没，看着就「大差不差」。

**规则**：
1. 前缀（第一题悬念句）保持期期不同——这是天然差异，别丢。
2. 后缀必须轮换，**不得连续两期用同一后缀**。
3. 后缀从 5 个公式轮着取：挑战式 / 结果承诺·段位 / 身份式 / 收藏指令 / 悬念式；段位后缀对准 `outro.scoreHints` 的段位名（文曲星下凡 / 出口成章 / 腹有诗书 / 小有才学）。

## 八、合规红线（写标题前必读）

依据 `docs/审核基准.md` 4.3 节与[知乎](https://zhuanlan.zhihu.com/p/149779630)禁用词：

- **零数字铁律**：禁用一切无来源数字（`90%/99% 的人`、`全国唯一`）；可用可验证数字（`10 题`、`答对 8 个`）；无出处数字改定性表述（`绝大多数人`、`没几个人`）。
- **禁用词**：`震惊`、`最`、`惊呆了`、`吓哭了`、`速看` 等夸张惊叹词；连续 `！！！`；`不看不是中国人` 式道德绑架。
- **不标题党**：标题与内容相符（视频号 5.2.1）；不把低俗词源做噱头放大。
- **标题≠内容**：不要全盘托出答案，留悬念给视频。

## 九、自检清单（交付前逐条过）

- [ ] 抖音标题 = 「第一题悬念句」+ 轮换后缀，后缀与上一期不同
- [ ] 抖音话题 ≤5（最好 3 个垂直词 + 2 个泛流量词）
- [ ] `publish.title`（视频号）与 `publish.douyin.title`（抖音）分别给，不共用
- [ ] 无 `90%/99%` 等无来源数字；无 `震惊/最/惊呆了` 等禁用词
- [ ] 标题没把答案说死，留了悬念
- [ ] 视频号标题带收藏/考孩子指令，抖音标题带数字或挑衅
