# 爆款快闪模板（BurstQuiz）使用说明

> 依据 2026-08-29 对标拆解（4 条「学霸都考哭了」系列爆款，点赞 1.4万 / 5.5万 / 10万 ×2）提炼的优势实现。
> 对标分析报告：`reports/20260829-0820-crack-文学常识对标.md`、`reports/20260829-0820-对标学习与选题参考.md`

## 一、模板提取了哪些爆款优势

| 对标优势 | 本模板实现 |
|---|---|
| 0 秒进题，首帧就是第一题 | 强制零片头（无论题库怎么配 introSeconds） |
| 每题 4.6–6.5 秒快问快答 | 每题 8 秒左右两段式：呈现 2.2s → 揭晓 2.8s → **题间停顿 1s**，无倒计时（可配置恢复倒计时） |
| 顶部常驻「全对，金榜题名」激励角标 | 顶部常驻「全对 = 学霸」金色角标 + 题号计数 |
| 底部常驻免责声明（合规话术） | 底部常驻「内容来源于公开资料」 |
| 标题/画面下收藏指令 | 底部常驻「❤ 收藏 · 考考孩子」+ 片尾 CTA 收口 |
| 3 秒短片尾 | 片尾 3 秒：大字结果承诺 + 点赞收藏关注 CTA |
| 标题公式「关键词 + 挑战词」 | 发布文案模板：如「古人的诗意外号，全对算你厉害」 |

音效与倒计时可配置：

- **答案音效**：快闪模板默认开启（揭晓时播「出正确答案」音效）；设 `timing.soundEffects = false` 切纯快闪（完全对标无音效版）。
- **作答倒计时**：题库给 `perQuestion.countdownSeconds > 0` 即恢复倒计时环 + 倒计时音效。例如 `countdownSeconds: 2` → 每题 8 秒（2.2 呈现 + 2 作答 + 2.8 揭晓 + 1 停顿），仍远快于经典模板的 16.5 秒/题。
- **题间停顿**：揭晓后、下一题前固定 `pauseSeconds`（burst 缺省 1 秒），给 TTS 朗读缓冲，避免「答案一出立刻读下一题」；在 `perQuestion` / `fill` 里可调（如 1.5）。
- **TTS 语速兜底（剪映「字幕转音频」对齐）**：剪映朗读约 4~5 字/秒，若字幕区间短于朗读时长，上一段音频会叠进下一段（听感重复/重叠）。burst 模式按 `timing.ttsWordsPerSecond`（缺省 4.5 字/秒）自动兜底每题时长：题干段（present+countdown）≥ 题干朗读 + 0.5s，答案段（reveal+pause）≥ 答案朗读 + 0.6s；长文本题自动拉长，字幕/画面/音频三者始终对齐。设 `ttsWordsPerSecond: 0` 关闭。
- **片尾答案回顾**：默认开启 12 秒，在片尾 CTA 之前逐题展示「题干 → 答案 → 完整解释」（仅画面、不进字幕，字号为老年观众加大）；设 `timing.summarySeconds: 0` 关闭，或给任意秒数调整停留时长。
- **字号**：快闪模板全部字号已按老年观众加大（题干 66-70、选项 52、答案回顾解释 38）。

视觉保留本项目宣纸风（差异化：对标是黑底大字红海），只升级信息节奏与话术。

## 二、如何启用

题库 JSON 的 `timing` 里加一行：

```json
"timing": {
  "fps": 30,
  "introSeconds": 0,
  "outroSeconds": 3,
  "pacing": "burst"
}
```

- `pacing: "burst"` 启用快闪节奏（每题 5 秒，呈现 2.2s + 揭晓 2.8s）。
- 可省略 `perQuestion` / `fill`；若要微调，显式给的值优先于 burst 默认。
- 填空题建议加短句 `punchline`（揭晓时的一行真相，比 explanation 短，也用于配音）。

可选 `publish` 新增字段（缺省用对标同款话术）：

```json
"publish": {
  "title": "古人的诗意外号，全对算你厉害",
  "douyin": { "title": "月亮的雅称是什么？答对三个算你牛" },
  "badge": "全对 = 学霸",
  "saveText": "❤ 收藏 · 考考孩子",
  "disclaimer": "内容来源于公开资料",
  "hashtags": ["万物雅称", "涨知识", "冷知识", "传统文化", "古诗词", "中国文化"]
}
```

## 三、渲染命令

```bash
node scripts/quiz/render-with-cover.mjs \
  --data=src/data/questions-burst-demo.json \
  --composition=BurstQuiz \
  out/burst-demo.mp4
```

产物：视频 + 封面（首帧进题画面）+ **片尾钩子图**（`out/<期号>-钩子.png`，把 `outro.hook` 口播钩子排版成宣纸风竖屏大字图，供发布配图 / 评论区置顶图 / 结尾贴图使用）+ SRT 字幕 + 发布文案（视频号/抖音双标题）。

- **答案已进视频（推荐）**：题库 `timing.summarySeconds` 开启片尾答案回顾（逐题展示题干→答案→解释，仅画面不进字幕），答案无需单独图片；`outro.answerHint` 在片尾 CTA 画面显示互动引导（如「都记住了吗，评论区对答案」）。
- **答案图默认不产出**：如需单独答案解释图 PNG（自动分页），加 `--answer-sheet` 开启。
- **片尾钩子字幕默认输出**（SRT 末尾带口播钩子，供剪映 TTS 朗读）；不需要口播钩子时加 `--no-outro-hook` 关闭。
- **文字版片尾（默认）**：结尾 3 秒「全对 = 学霸 + 点赞·收藏·关注」，钩子口播落在片尾段内；若某期想改为无片尾帧（视频在最后一题结束，钩子口播移至视频结束点之后，用户自行导入钩子图/答案图），设题库 `timing.minimalOutro: true`。
- 钩子图取 `outro.hook` 文案，按句号/问号拆行、字号自适应；只渲染 PNG，不进视频。
- 答案解释图（`--answer-sheet` 开启时）分页由 `src/answerSheet.ts` 的 `computeAnswerPages()` 决定（题干 42px / 答案 40px / 解释 31px，单页可用高度约 1540px，超限自动翻页），组件与脚本共用同一函数保证页数一致。

## 背景皮肤规则

- **选择题（含快闪）**：黄色宣纸底 `assets/bg-paper.svg`（组件默认；快闪模板沿用 `cloudSrc: null, drift: 0.04`）。
- **填空题（万物雅称）**：青灰白底 `assets/bg-yacheng.svg`。

## 四、技术要点（后续维护）

- 零片头在三处保证：`buildTimeline`（pacing=burst 强制 introFrames=0）、`BurstQuiz` 组件（强制 introSeconds=0）、`Root.calcTimeline`（BurstQuiz 合成元数据同步强制），确保时长元数据与画面一致。
- **时间轴单一入口（铁律，2026-09-10 事故后定）**：`Root.calculateMetadata`（算合成总时长）与 `BurstQuiz` 组件（排每题画面与配音起点）**必须都调 `buildRenderTimeline(props)`**，任何一处直接调裸 `buildTimeline(data)` 都会退回字/秒估算。
  - 事故现象（船长反馈「有时候题目没读完，就读答案了」）：`calculateMetadata` 传了 `audioMeasurements`、`BurstQuiz` 却没传 → ①答案语音按估算的 `revealStart` 提前开声，与题干尾巴**叠音**（21 期 q7：题干实测 8.23s，旧答案起点 6.93s，重叠 1.30s；q3 重叠 0.31s——估算比实测长的题（q1/q4/q9）反而没事，所以表现成「有时候」）；②每题 slot 偏短，题干音频被外层 `Sequence` 截断；③内容实长 113.8s vs 合成时长 117.3s，片尾后多出约 3.5s 空尾。
  - 防回归：`tests/burst-measured-audio.test.mjs` 含「答案口播起点 ≥ 题干实测」的行为断言 + 「组件/元数据都必须走 buildRenderTimeline」的源码守卫。
- 展示流（`ScrollShow`）无此问题：`scrollTimeline(data, audioMeasurements)` 直接在组件内算，与 `calcScrollTimeline` 同源。
- **片头钩子也配音（2026-09-10 补）**：`gen-burst-tts.py` 增合成 `__intro__-intro.mp3`（台本 = `intro.voice` ＞ **封面大字 `intro.title`**；**不念挑战词 `intro.subtitle`**——画面已有，念出来重复，船长 2026-09-10 定调；`hookSeconds: 0` 时跳过），measurements 里写 `introHookMs`，`buildTimeline` 按「实测 + 0.5s」拉长 `hookFrames`，`BurstQuiz` 在钩子 Sequence 内挂该音轨（仅当实测到这段音频时才挂，缺 mp3 静音不报错）。此前 `hookAudioMs` 是无人喂数据的预留参数，片头字卡一直是静音——表现就是「开头只有 BGM」。
- 快闪场景 `src/scenes/BurstScene.tsx` 同时处理选择题与填空题。
- 揭晓口播间隔在快闪模板缩短为 0.8 秒（`QuestionVoiceTracks` 的 `punchlineDelaySeconds`）。
- 经典模板 `LiteratureQuiz` 已删除（见 git 历史），老题库改走 BurstQuiz。
