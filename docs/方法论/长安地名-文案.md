| 知识点 | 依据 | 置信 |

| 刘邦初欲都洛阳，娄敬进言都关中，张良力挺，即日西都 | 《史记·刘敬叔孙通列传》《留侯世家》 | 高 |
| 汉高祖七年萧何营未央宫，长安城落成 | 《史记·高祖本纪》《汉书·高帝纪》 | 高 |
| 「建久安之势，成长治之业」 | 贾谊《治安策》（《汉书·贾谊传》），文中作「注脚」表述，未称长安得名于此，无时间错位 | 高 |
| 隋文帝于汉长安城东南营建新都「大兴城」，因杨坚早年封大兴郡公得名；唐复名长安 | 《隋书·高祖纪》《唐六典》通行说法 | 中高（正史载大兴城，得名缘由为通行解释） |
