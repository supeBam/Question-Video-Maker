## 二、选型流程（新人物 / 新旁白）

1. **查库**：先看本表「可复用给」列，气质匹配 → 直接把 voice_id 写进对白 JSON 的 `voices`。
2. **无匹配 → 定制**：改 `scripts/dialogue/design-voices.py` 的 VOICES 列表（写 prompt + 试听文本），运行生成，**试听确认**后登记两处（JSON + 本表）。
3. **语速**：旁白/叙述类建议 1.1（防拖沓）；人物对白 1.0。写进对白 JSON 的 `speeds` 字段。
4. **试听归档**：新音色的试听文件拷入 `public/assets/voice-previews/`（命名与音色名一致），并在本表补试听链接。

## 三、定制音色（design-voices.py）

```bash
# 改 scripts/dialogue/design-voices.py 的 VOICES 列表（名称/prompt/试听文本）后：
.venv-asr/bin/python scripts/dialogue/design-voices.py
# 输出 voice_id + 试听 mp3（out/试听-*.mp3），确认后登记进 JSON 和本表
```

**prompt 写法经验**（踩坑总结）：
- ❌ 避免「解说员、播音员、字正腔圆、沉稳有力」——会生成拖沓的播音腔（第一版旁白的教训）
- ✅ 用「像老朋友聊天讲故事、自然松弛、流畅利落、带即兴起伏」——接近真人质感
- ✅ 气质锚点用**原文/身份描述**（如「清代儒臣」「道家智者」），不要用在世名人名字（红线：不克隆真实名人声音）

## 四、已知坑

- voice_design 的响应字段在**顶层**（`voice_id` / `trial_audio`），不在 `data` 里（t2a_v2 才有 `data` 包裹）——解析别写错。
- 音色设计生成的音色需**成功调用一次合成**才激活（get_voice 才查得到）。
- 语速是独立旋钮：音色偏慢就在对白 JSON 的 `speeds` 里提速，不必重新设计音色。
- **克隆音色响度高于公共音色（易削波）**：王立群（`xian-laokie-01`）合成输出 mean 约 -11 dB、峰值约 -0.2 dB，比公共音色（mean 约 -23 dB、峰值约 -7 dB）响 12 dB。答题线 `src/questionVoiceTracks.ts` 的人声增益 `VOICE_VOLUME=4`（+12 dB）是按公共音色标定的，直接套克隆音色会削波成杂音。**用王立群音色出答题/特辑时，必须在 render:auto 加 `--tts-arg=--voice-vol=0.25`**（`gen-burst-tts.py` 新增参数，2026-09-25 成语第33期踩坑修复）。地名唠嗑线（compose-video.py）走 loudnorm+真峰限制，不受此影响。
