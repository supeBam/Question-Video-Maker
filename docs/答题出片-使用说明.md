# 答题出片 · 使用说明

> 适用范围：本项目的**答题类短视频**出片（选择题 / 填空题快闪模板）。
> 说明：从 2026-09-10 起，答题类只保留**快闪模板（BurstQuiz）**一种渲染模式；旧的经典模板（LiteratureQuiz / 万物雅称经典填空题 / 钩子图 / 答案图）已清除，历史题库 JSON 文件保留作归档，不再渲染。

---

## 一、两个出片指令

答题出片只有两种模式，都用快闪模板，区别只在「配音谁来做」：

| 指令 | 模式 | 配音来源 | 产出物 |
|------|------|---------|--------|
| `npm run render:auto` | 一键成片 | MiniMax TTS 自动合成（项目内，无需剪映） | 成片（带配音）+ 封面 + 发布内容 |
| `npm run render:manual` | 手工模式 | 剪映「字幕转音频」手工配音 | 成片（静音+BGM）+ 字幕文件 + 发布内容 + 封面 |

> 两条指令**都不产出**钩子图、答案图（快闪模板已在片尾画面里渲染了口播钩子与本期答案）。

---

## 二、命令用法

### 1. 一键成片（推荐）

```bash
npm run render:auto -- out/成语-第17期.mp4 \
    --data=src/data/questions-260910-1.json \
    --video-label=成语-第17期
```

产出：
- `out/成语-第17期.mp4` —— 成片（含 MiniMax 口播配音 + BGM）
- `out/成语-第17期.png` —— 封面
- `out/成语-第17期.txt` —— 发布内容（视频号 + 抖音标题/话题）

**前置条件**：
- 项目根目录有 `.minimax.key`（MiniMax API key）
- 本机有 `.venv-asr/bin/python` + `ffmpeg`/`ffprobe`
- 首次合成会调 MiniMax 接口；之后重复跑走增量缓存（改一句只重合成一句，不重复扣费）

### 2. 手工模式

```bash
npm run render:manual -- out/成语-第17期.mp4 \
    --data=src/data/questions-260910-1.json
```

产出：
- `out/成语-第17期.mp4` —— 成片（静音，仅 BGM）
- `out/成语-第17期.srt` —— 字幕文件（剪映「字幕转音频」导入用）
- `out/成语-第17期.png` —— 封面
- `out/成语-第17期.txt` —— 发布内容

然后：把 SRT 导入剪映 → 「文本朗读」生成口播 → 导出成片。

## 三、可选参数

| 参数 | 作用 | 适用 |
|------|------|------|
| `--data=<题库JSON路径>` | 指定题库文件 | 两种模式 |
| `--video-label=<期号标签>` | 覆盖默认 video-label（缺省取 episodeLabel） | 一键成片 |
| `--tts-arg=<gen-burst-tts.py参数>` | 透传给 TTS 脚本，如 `--tts-arg=--voice-stem=male-qn-jingying` | 一键成片 |
| `--no-outro-hook` | 去掉 SRT 片尾口播钩子段 | 手工模式 |
| `--srt-only` | 只重生成字幕/封面/发布内容，不渲染视频 | 手工模式 |

> 位置参数（非 `--` 开头）是输出视频路径；必须 `.mp4` 结尾。

## 四、音色与语速（一键成片）

`gen-burst-tts.py` 默认三套音色（合规 MiniMax 公共音色，非名人克隆）：

| 段 | 音色 | 语速 |
|----|------|------|
| 题干 | 磁性男声 `male-qn-qingse` | 1.0 |
| 答案 | 情感女声 `female-shaonv` | 1.0 |
| 片尾口播钩子 | 磁性男声（同题干） | 1.0 |

覆盖音色（一次性）：

```bash
npm run render:auto -- out/成语-第17期.mp4 \
    --data=src/data/questions-260910-1.json \
    --video-label=成语-第17期 \
    --tts-arg=--voice-stem=male-qn-jingying \
    --tts-arg=--voice-answer=female-shaonv
```

> 合规红线：只用 MiniMax 公共音色，**不克隆任何真实名人的声线**（民法典第 1023 条对自然人声音的保护参照肖像权）。

## 五、音频驱动视频时长

一键成片时，视频时长由 TTS 实测音频时长自动推导：

1. `gen-burst-tts.py` 合成每段配音 → `ffprobe` 实测时长 → 写 `out/<label>-audio-measurements.json`
2. `buildTimeline` 按「实测时长 + 缓冲」推算每题呈现/揭晓段，确保口播念完再切下一题
3. 片尾口播钩子（如「你全对了吗？评论区告诉我…」）也按实测 + 2s 缓冲拉长片尾

所以**换音色/改文案后视频时长会自动跟着变**，不用手工调 `ttsWordsPerSecond`。
