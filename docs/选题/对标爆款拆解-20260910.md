## 二、今天新抓的结构样本（书香满屋《万物雅称》，详情 API 实测）

- 账号 9.6 万粉（「只推荐读过的好书」），81 秒竖屏，挂图书小黄车（16.8 元，月销 3000+）——**一条雅称视频撑起带货闭环**。
- 文案钩子：**「当万物失去诗意的名字，世界就少了灵魂。」**——感性共鸣式，不是「答对算你牛」的挑衅式。
- 对我们的启示（结合 86% 中老年画像）：
  1. 挑衅式后缀（「算你牛」）在年轻盘有效，但我们的主力受众 40+ 更吃「诗意/怀旧/讲给孩子」的共鸣式；
  2. 雅称主题天然带「中式美学」滤镜，与我们宣纸视觉基调完全契合，**是本公司最能「借力外部验证」的一条线**。

## 三、爆款预判门禁（出题前硬性自检，从本期起生效）

出题前每道题（每期选题）必须回答三个问题，答不上就降级为「试做」（试做产能 ≤20%）：

1. **对标映射**：这个选题/钩子在对标爆款里有没有先例（本表 §一 或后续补充）？→ 记录出处。
2. **受众匹配**：这个结构在 40+ 中老年盘上成立的理由是什么（画像/评论反馈/历史数据）？→ 一句话。
3. **结构差异**：我们复制的是「结构」（母题/句式/节奏），内容与文案是原创、且过查重与读音审校吗？→ 确认。

主力产能 = 有对标映射 + 受众匹配的选题；试做产能 = 只有直觉的选题。**这就是「我出题不再凭感觉」的制度化。**

## 四、由外部验证直接推导的排期动作

2. **标题钩子双轨制**：视频号主打感性共鸣式（「当万物失去诗意的名字」类），抖音保留挑战式（「不服来战」类）——两平台受众结构不同，正好复用既有分平台发布能力。
