| 3 | 上下其手 | 玩弄手段、暗中作弊 | 动手动脚 / 非礼 | 《左传·襄公二十六年》伯州犁「上其手」「下其手」暗示俘虏指认，暗中作弊 | 不是「咸猪手」，是「暗箱操作」 |
| 4 | 首鼠两端 | 犹豫不决、迟疑观望 | 首尾两端 / 两头讨好 / 表里不一 | 《史记·魏其武安侯列传》「何为首鼠两端」 | 不是「两头都占」，是「拿不定主意」 |

## 五、给内容创作的出题提示

1. **题型**：选择题（type: "choice"），沿用 `questions-260901-1.json` 结构：每题 `stem / options(4) / answerIndex / explanation / punchline`；解析必须带出处原文（本清单第三列已给），满足审核基准 3.1「权威出处」。
2. **题干长度**：快闪呈现 2.2s、TTS 语速 4.5 字/秒兜底，题干 + 选项控制在每行 ≤14 字、题干 ≤2 行（参考第 04 期句式：「「罄竹难书」是\n形容什么？」）。
3. **选项设计**：正确答案 = 本义；3 个干扰项 = 常见误用 + 字面拆解 + 无厘头（参考第 04 期「危言危行」的选项结构）；干扰项不得有常识硬伤。
4. **punchline**：≤16 字一句话点破，句式参考「××是××，××=××」（如「刊是删改，改不得的话才叫不刊之论」）。
5. **合规注意（已按审核基准预判）**：
   - 「上下其手」：涉及「动手动脚/非礼」的低俗联想——题干与标题只讲词源（「暗中作弊」），解析只用《左传》原文，不得放大低俗联想（审核基准 4.2）；
   - 「豆蔻年华」：解说注明「十三四岁」源自杜牧「十三余」，避免被质疑年龄口径；
   - 全部词都有古籍原文，无需「据传」标注，但解析引用原文务必逐字核对。
6. **题库 JSON 生成后**：按 AGENTS.md 把 10 题追加登记到 `题库记录.md`「成语（选择题）」段落（本义误解类），并同步 `docs/选题归档.md` 选题索引（成语第 05 期，`questions-260901-2.json` 或当日最新序号）。
