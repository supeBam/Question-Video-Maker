## 四、归档规则（保持干净）

1. **一天一个新文件**：当天第一期为 `questions-YYMMDD-1.json`，同日第二期 `-2`，依此类推；次日换新日期。
2. **不覆盖历史文件**：只新增；需覆盖 `questions.json` 时必须显式确认。
3. **出题后同步两处**：① 本表（选题索引）；② `../题库记录.md`（查重登记）。
4. **特殊情况**：备份放 `questions-back.json`（仅一份，勿多份堆积）；示例/专题用语义化命名（如 `questions-wanwu-yacheng.json`）。

### 按文件名渲染某一期（不用改 questions.json）

```bash
node scripts/render-with-cover.mjs out/<期号>.mp4 --data=src/data/questions-YYMMDD-N.json
```

`--data=` 指向哪个题库文件，视频、封面、字幕、发布文案就都用哪份数据（脚本内部通过 `--props` + `calculateMetadata` 实现，无需再把内容复制进 `questions.json`）。
