## 一、项目定位

一套「**换一份题库 JSON 就能出下一期**」的竖屏答题短视频生成器，基于 [Remotion](https://www.remotion.dev/)（React 写视频）。

- **成片规格**：1080 × 1920（9:16 竖屏，适配视频号/抖音）｜ 30 fps ｜ H.264 / MP4
- **视觉基调**：宣纸米黄底 + 金 / 朱砂点缀（浅色护眼，当前主题，见 `src/theme.ts`）
- **核心卖点**：时间轴完全由题库 JSON 推导，增删题目**无需改任何代码**；支持三种题型在同一期混排。

## 三、两种题型

题库 `QuizData.questions[]` 是一个判别联合（discriminated union），同一期可混排两种题型：

| 题型 | `type` | 节奏 | 场景文件 | 说明 |
|---|---|---|---|---|
| 选择题 | `"choice"`（可省略） | 三段式：呈现 → 作答 → 揭晓 | `scenes/QuestionScene.tsx`（经典）/ `scenes/BurstScene.tsx`（快闪） | A/B/C/D 选项，正解高亮、错误项降透明 |
| 填空题（万物雅称） | `"fill"` | 三段式：呈现 → 思考 → 揭晓 | `scenes/FillScene.tsx`（经典）/ `scenes/BurstScene.tsx`（快闪） | 问「X 的雅称」，揭晓雅称大字 + 解释 |

类型定义、题型判别函数（`isFill`）与时间轴推导全部在 `src/types.ts`。

## 四、核心概念：从题库到成片

```
题库 JSON (src/data/*.json)
   │  一次构建推导（buildTimeline）
   ▼
Timeline { fps, introFrames, outroFrames, slots[], totalFrames }
   │  注册 Composition（Root.tsx，3 个合成共用同一组件）
   ▼
LiteratureQuiz 组件（按 slot.kind 路由到对应场景）
   │
   ▼
scenes/*.tsx  →  components/*.tsx  →  theme.ts / animations.ts
```

- **时间轴推导**：`src/types.ts` 的 `buildTimeline(data)` 把「片头 + Σ每题时长 + 片尾」换算成帧，`totalFrames` 直接作为合成时长，所以换题量不用改 `durationInFrames`。
- **背景连续**：`Background` 放在合成最外层（所有 `Sequence` 之外），Ken Burns 推镜 + 祥云横移整片不重置。
- **场景间过渡**：每题场景内做 10–12 帧淡入淡出。

## 五、合成（Composition）注册

`src/Root.tsx` 注册了 **4 个合成**：

| 合成 id | 数据源 | 用途 |
|---|---|---|
| `LiteratureQuiz` | `src/data/questions.json` | 当前活跃题库（中国文化冷知识 第 13 期，经典模板） |
| `WanwuYacheng` | `src/data/questions-wanwu-yacheng.json` | 万物雅称填空题专题（经典模板） |
| `BurstQuiz` | `src/data/questions-burst-demo.json` | 爆款快闪模板（词语代称/成语等，`pacing: "burst"`） |
| `OutroHook` | `src/data/questions-burst-demo.json` | 片尾钩子图（仅 still 渲染 PNG，不进视频） |

> 新增一期通常**不新增合成**：渲染走 `LiteratureQuiz`（经典）或 `BurstQuiz`（快闪）合成，用 `--data` 指定题库文件即可；仅当需要新增独立合成（如新专题）时才在 `Root.tsx` 加一个 `<Composition>`。

## 六、常用命令

```bash
# 可视化预览工作台（改文案实时看效果，右上角切合成）
npm run dev                 # remotion studio  → http://localhost:3000

# 按指定题库文件预览（任意 questions-*.json，无需切换合成）
npm run dev:data -- --data=src/data/questions-wanwu-yacheng.json

# 一键出片（视频 + 封面 + 字幕 + 发布文案），用当前 questions.json
npm run render              # node scripts/render-with-cover.mjs

# 指定输出文件 / 合成 / 数据源
node scripts/render-with-cover.mjs out/xxx-ep02.mp4 --data=src/data/questions-wanwu-yacheng.json

# 只重生成字幕 + 发布文案（不重渲染视频）
node scripts/render-with-cover.mjs out/xxx-ep02.mp4 --data=src/data/xxx.json --srt-only
```

> `--data=` 指定的题库文件会**真正驱动视频画面**（不只是字幕/文案）：脚本把该文件包成 props 临时文件，用 `--props` 传给 `remotion render/still`，`Root.tsx` 的 `calculateMetadata` 据此动态重算时长/帧率。临时文件 `out/.remotion-props.json` 出片后自动删除。渲染任意一期：`node scripts/render-with-cover.mjs out/ep14.mp4 --data=src/data/questions-260826-1.json`。

# 单帧封面 / 高画质渲染
npx remotion still LiteratureQuiz out/cover.png --frame=90
npx remotion render LiteratureQuiz out/ep02-hq.mp4 --crf=16 --jpeg-quality=95

# 快闪模式出片（BurstQuiz 合成）
node scripts/render-with-cover.mjs out/成语-第01期.mp4 --data=src/data/questions-260830-2.json --composition=BurstQuiz

# 跑测试
npm test
```

## 七、做一期新视频的完整流程

1. **出题前先查重**：读 [`../题库记录.md`](../题库记录.md)（及 `src/data/` 下所有题库），避免同一事物/雅称/知识点/诗句线索重复。
2. **生成题库 JSON**：用技能 `generating-quiz-json`（见 §十），默认输出 `src/data/questions-YYMMDD-N.json`；或手改 `src/data/questions.json`。
3. **本地预览**：`npm run dev`，切到对应合成检查版式。
4. **出片**：`node scripts/render-with-cover.mjs out/<期号>.mp4 --data=...`（快闪加 `--composition=BurstQuiz`），产物为 `out/` 下的 `.mp4` + `.png`（封面）+ `-钩子.png`（片尾钩子图，不需要时加 `--no-hook-image`）+ `.srt` + 发布文案（单个 txt）。
   > **出片纪律（2026-09-08 用户确认）**：渲染一律直接用上方的 `render-with-cover.mjs` 命令行，**禁止再新建 `export-*.mjs` 之类的专用导出脚本**——该入口已支持 `--data=`、`--composition=`、`--no-hook-image`（不产片尾钩子图，钩子图由用户自行导入）、`--srt-only` 等全部参数，一条命令即可，多包一层脚本纯属多余。示例：`node scripts/render-with-cover.mjs out/成语-第16期.mp4 --data=src/data/questions-260908-3.json --composition=BurstQuiz --no-hook-image`。
5. **登记题目**：把新题目追加到 `../题库记录.md` 对应主题段落（与题库保持同步）。

## 八、音频体系

| 层 | 文件/模块 | 说明 |
|---|---|---|
| BGM | `public/assets/bg-audio/*.mp3` | 题库 `bgm.{enabled,file,volume}` 控制，`LiteratureQuiz` 里 `<Audio loop>` |
| 音效 | `public/assets/audio/*.mp3` | `QuestionSoundEffects` + `getQuestionSoundTiming`：倒计时「开始三秒倒计时」、揭晓「出正确答案」 |
| 配音（TTS） | `src/questionVoiceTracks.ts` → `assets/tts/{series}-{episodeLabel}/{questionId}-{question|answer|punchline}.mp3` | 由 `QuestionVoiceTracks` 组件在 `voiceOver.enabled` 时播放；音频由技能 `listenhub-voice` 生成（见 §十） |

- 当前所有题库 `voiceOver.enabled = false`，且 `public/assets/tts/` 尚未生成（TTS 文件按需用技能产出）。
- `punchline` 是选择题揭晓时的「一句真相」口播（比 `explanation` 短），答案语音播完 1.2s 后接播。

## 九、发布物

`scripts/render-with-cover.mjs` 一次产出（路径 = 视频路径去掉 `.mp4` 后缀）：

| 产物 | 后缀 | 说明 |
|---|---|---|
| 视频 | `.mp4` | Remotion 渲染 |
| 封面 | `.png` | `--frame=90` 截帧 |
| 字幕 | `.srt` | 按题型生成（题干 / 答案 / 片尾 hook） |
| 发布文案 | `.txt`（单个文件） | 文件内分「视频号 / 抖音」两段，各含标题 + 话题；`SERIES_TAGS` 按栏目给默认话题，题库 `publish` 字段可覆盖 |

## 十、协作约定与可用技能

### 协作约定（`../AGENTS.md`）
- **语言**：对用户的说明、文档、计划统一中文；代码标识符/命令/路径可用英文。
- **题目查重**：出题前查 `题库记录.md`；新题生成后回写记录，保持同步。

### 项目内置技能（`.agents/skills/`）
| 技能 | 作用 |
|---|---|
| `generating-quiz-json` | 按主题/题量/受众生成完整 `QuizData` JSON，并跑 Python 校验器 |
| `listenhub-voice` | 端到端 TTS 生成配音（ListenHub-Voice-1.0，配置在 `.listenhub/listenhub-voice/config.json`） |

> `listenhub-voice` 技能文件当前在 git 里显示为已删除（working tree 状态），使用前若报缺失需重新安装该技能。

## 十二、注意事项（踩坑记录）

- `remotion.config.ts` **不要**设 `setChromiumOpenGlRenderer("angle")`，会导致 headless Chrome 的 `requestAnimationFrame` 不触发、渲染卡死（保持默认）。
- 本机 npm 并发请求慢（~15s/req），装依赖加 `--maxsockets=3`。
- 中文显示成方块：`theme.ts` 字体栈里的字体本机不存在，换成 `Microsoft YaHei` / `SimSun` / `KaiTi`。
- 所有字号 ≥ 24px（手机小屏可读）；选项单行建议 ≤ 12 字，题干建议 ≤ 40 字（用 `\n` 断句）。
