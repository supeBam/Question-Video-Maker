## 二、核心源码文件职责

| 文件 | 职责 |
|---|---|
| `src/types.ts` | **全项目最核心**：`QuizData` / `ChoiceQuestion` / `CrosswordQuestion` / `FillQuestion` / `QuestionSlot` / `Timeline` 等类型；`buildTimeline()` 把题库推导成帧级时间轴；题型判别 `isCrossword` / `isFill`；节奏兜底值 |
| `src/theme.ts` | 唯一视觉源：`colors`（宣纸米黄/金/朱砂/翠绿）、`fonts`（宋体/楷体/黑体/数字）、`layout`（1080×1920 + 安全区）、`fontSize` |
| `src/LiteratureQuiz.tsx` | 主合成：`Background`（Sequence 外）+ BGM + 片头/片尾 Sequence + 按 `slot.kind` 路由到 `QuestionScene` / `CrosswordScene` / `FillScene` |
| `src/Root.tsx` | 注册合成：`LiteratureQuiz` / `CrosswordQuiz` / `WanwuYacheng`，各自用 `buildTimeline` 算时长 |
| `src/crossword.ts` | 纯函数 `buildGrid(clues)`：包围盒 → 填格 → 起点编号 → 留白列表；交叉点字符冲突告警 |
| `src/animations.ts` | `fadeSlideUp` / `fadeSlideIn` / `stagger` / `popIn` / `sceneFade` / `lerp` |
| `src/questionSoundTiming.ts` | 纯函数 `getQuestionSoundTiming`：算倒计时音效起止、答案音效起点 |
| `src/questionVoiceTracks.ts` | 纯函数 `getQuestionVoiceTracks`：拼出 TTS 文件路径 `assets/tts/{series}-{episodeLabel}/{id}-*.mp3` |

### 组件（`src/components/`）

| 文件 | 职责 |
|---|---|
| `Background.tsx` | 全片连续背景：宣纸底 + 推镜 + 祥云横移 |
| `Header.tsx` | 顶部信息条：栏目名 · 期号 ｜ 题号计数 |
| `CountdownRing.tsx` | 倒计时环：进度环 + 跳动数字 + 警戒变色 + 毛笔外圈 |
| `QuestionCard.tsx` | 题干卡片：题号小印 + 按字数自动缩放字号 |
| `OptionItem.tsx` | 选项行：idle / correct / wrong 三态 |
| `AnswerReveal.tsx` | 答案揭晓条：印章 + 「正确答案 X」+ 解析 |
| `CrosswordGrid.tsx` | 纵横填字网格：空洞/已给字/留白/揭晓高亮 + 起点序号 |
| `QuestionSoundEffects.tsx` | 挂载倒计时 + 正确答案两段音效 |
| `QuestionVoiceTracks.tsx` | 挂载题目/答案/一句真相三段配音 |

### 场景（`src/scenes/`）

| 文件 | 职责 |
|---|---|
| `IntroScene.tsx` | 片头：印章 → 栏目 → 主标题 → 副标题 → 提示条 → 落款 |
| `QuestionScene.tsx` | 选择题三段式：呈现（题干+选项入场）→ 作答（倒计时）→ 揭晓（高亮+解析） |
| `CrosswordScene.tsx` | 诗词填字两阶段：展示（网格+线索区）→ 揭晓（补全+出处+赏析） |
| `FillScene.tsx` | 填空题三段式：呈现 → 思考（倒计时+留白）→ 揭晓（雅称大字+解释） |
| `OutroScene.tsx` | 片尾：成绩自评卡 → CTA → 落款 |

## 三、数据流

```
questions.json ──import──▶ Root.tsx ──buildTimeline──▶ totalFrames/fps
                                │ defaultProps.data
                                ▼
                        LiteratureQuiz(data)
                                │ buildTimeline(data)
                                ├── Background (bg src/cloudSrc/drift)
                                ├── bgm.enabled ? <Audio loop>
                                ├── Sequence(片头) ──▶ IntroScene
                                ├── slots.map ──▶ 按 kind 路由:
                                │     choice   → QuestionScene   → QuestionCard/OptionItem/AnswerReveal/CountdownRing
                                │     crossword→ CrosswordScene  → CrosswordGrid(→ buildGrid)
                                │     fill     → FillScene       → QuestionCard/CountdownRing
                                └── Sequence(片尾) ──▶ OutroScene
```

时间轴推导规则（`buildTimeline`）：

- `introFrames = introSeconds × fps`，`outroFrames = outroSeconds × fps`。
- 选择题/填空题每题 = `present + countdown + reveal`；诗词填字每题 = `display + answer`。
- 每种题型支持 `timingOverride` 单题覆盖；`crossword` / `fill` 全局节奏缺省时用兜底值（crossword 45s/7s，fill 3.5s/6s/7s）。
- `totalFrames = introFrames + Σ每题时长 + outroFrames`。

## 四、题库文件（`src/data/`）与命名约定

- `questions.json` —— **当前活跃题库**（中国文化冷知识 第 13 期，4 题）。
- `questions-YYMMDD-N.json` —— 历史期题库，`YYMMDD`=日期、`N`=当天序号（由技能 `generating-quiz-json` 生成，例 `questions-260824.json`）。
- `questions-crossword-demo.json` —— 诗词填字纵横示例（单题，`CrosswordQuiz`）。
- `questions-wanwu-yacheng.json` —— 万物雅称填空题专题（`WanwuYacheng`）。
- `questions-back.json` —— 备份文件。

字段速览（完整见 `.agents/skills/generating-quiz-json/references/quiz-data-schema.md`）：

- 顶层：`meta` / `timing` / `intro` / `outro` / `voiceOver` / `bgm` / `publish?` / `background?` / `questions[]`。
- `background`（可选）：`src` 背景图、`cloudSrc` 祥云（`null` 关）、`drift` 推镜幅度 —— 换专题皮肤。
- `publish`（可选）：`title` / `hashtags` 及 `douyin` / `wechat` 覆盖 —— 缺省由脚本按栏目推导。

## 五、脚本（`scripts/`）

| 文件 | 职责 | 关键导出/参数 |
|---|---|---|

## 七、模块依赖（关键链路）

```
index.ts → Root.tsx → LiteratureQuiz.tsx
                        ├→ components/Background.tsx ── theme / animations
                        ├→ scenes/IntroScene.tsx      ── theme / animations
                        ├→ scenes/QuestionScene.tsx   ── components/{Header,CountdownRing,QuestionCard,OptionItem,AnswerReveal,QuestionSoundEffects,QuestionVoiceTracks}
                        │                                └→ questionSoundTiming / questionVoiceTracks
                        ├→ scenes/CrosswordScene.tsx  ── components/{Header,CountdownRing,CrosswordGrid,QuestionSoundEffects} + crossword.ts
                        ├→ scenes/FillScene.tsx       ── components/{Header,CountdownRing,QuestionCard,QuestionSoundEffects}
                        └→ scenes/OutroScene.tsx      ── theme / animations
```

所有颜色/字号取自 `theme.ts`（组件内不写死）；所有纯逻辑（时间轴、网格、音效时间点、配音路径）抽成无副作用的 `*.ts` 纯函数，便于 `tests/` 直测。

## 八、资源目录约定（`public/assets/`）

| 子目录 | 用途 |
|---|---|
| `assets/*.svg` | 背景图（`bg-paper.svg` 默认 / `bg-ink.svg` 水墨 / `bg-yacheng.svg` 雅称）、`cloud-pattern.svg` 祥云、`seal-mark.svg` 印章、`ring-brush.svg` 圆环、`paper-texture.svg` 备用纹理 |
